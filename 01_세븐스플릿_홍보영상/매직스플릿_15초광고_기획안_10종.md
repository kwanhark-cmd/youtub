# 매직스플릿 15초 광고 기획안 10종
### — 각기 완전히 다른 장르·톤·영상 문법의 독립 기획안 —

**제품:** 매직스플릿 (유진투자증권 × 스플릿인베스트, 모바일 자동 분할매매)
**포맷:** 각 15초 (TV/유튜브 겸용, 9:16 리사이즈 별도)
**작성일:** 2026-11-10
**원칙:** 10편 모두 장르(코미디/공포/다큐/애니/SF/드라마/예능/무성영화/ASMR/뉴스), 촬영 문법, 사운드, 색감이 겹치지 않도록 설계. 어떤 두 편을 연달아 봐도 같은 캠페인으로 느껴지지 않을 만큼 다른 결과물이 나온다.

## 1안. 「개미 대장군」 — 사극 하이텐션 코미디
- **장르/톤:** 사극 패러디 × 하이텐션 밈 광고 (G마켓 '1일이야' 문법 계승)
- **비주얼:** 원색 크로마키 세트, 과장된 CG, 빠른 줌인/줌아웃
- **15초 흐름:** 폭락 차트 앞 장군 복장 모델 등장(0-3) → 폰 터치로 거대 캔들차트가 장작처럼 7조각 "쩍!"(3-6) → 조각들이 황금코인으로 변해 띠링띠링, 모델 어깨춤(6-10) → 손가락 7개 "7종목 7차수, 무료야!"(10-13) → 로고+징글(13-15)
- **카피:** "물 타지 마라… **쪼개!** 오늘부터 분할이야!"
- **사운드:** 국악 타악 + EDM 드랍 후크송
- **노리는 효과:** 중독성·밈화·숏폼 챌린지 확산

## 2안. 「강물은 쪼개져 바다로 간다」 — 자연 다큐멘터리 시네마틱
- **장르/톤:** 내셔널지오그래픽풍 고요한 명상 다큐. 1안과 정반대의 정적인 품격
- **비주얼:** 드론 항공 실사(또는 생성영상) — 하나의 큰 강이 삼각주에서 일곱 갈래로 갈라져 바다에 닿는 풍경. 골드아워 색감, 롱테이크
- **15초 흐름:** 거대한 강의 부감(0-4) → 일곱 갈래로 갈라지는 삼각주(4-9) → 바다와 만나며 반짝이는 수면(9-12) → 수면 위로 미니멀 로고(12-15)
- **카피(중저음 성우):** "강은, 쪼개져 흐를 때 바다에 닿는다. 투자도 그렇다. — 매직스플릿"
- **사운드:** 첼로 + 물소리 앰비언트. 효과음 없음
- **노리는 효과:** 브랜드 격조, 40-60대 자산가층 신뢰 형성. TV 뉴스 시간대 적합

## 3안. 「새벽 2시의 문자」 — 감성 로맨스 드라마
- **장르/톤:** 멜로 드라마 무드의 반전 코미디. 영화 예고편 같은 색보정
- **비주얼:** 야간 실내, 창밖 도시 불빛, 얕은 심도 클로즈업
- **15초 흐름:** 새벽, 뒤척이는 주인공. 폰 진동(0-3) → 화면: "자니…? 나야. 방금 3차 매도됐어"(3-7) → 주인공 벌떡 일어나 폰을 끌어안고 울컥(7-11) → 진지한 고백: "우리… 오늘부터 분할이야."(11-13) → 로고(13-15)
- **카피:** "잠든 사이에도, 네 생각뿐이야. — 애프터마켓까지 자동매매"
- **사운드:** 피아노 발라드 → 반전 순간 레코드 스크래치
- **노리는 효과:** 2030 연애 밈 공감대, SNS 공유. B컷으로 커플/솔로 버전 확장 용이

## 4안. 「개미 vs 곰」 — 2D 액션 애니메이션
- **장르/톤:** 일본 소년만화풍 2D 애니. 실사 없음 — 유일한 풀 애니 안
- **비주얼:** 셀 애니 작화, 스피드라인, 임팩트 프레임
- **15초 흐름:** 거대한 곰(하락장)이 도시를 부수며 포효(0-3) → 작은 개미 전사가 홀로 맞섬, 절체절명(3-6) → 개미가 검을 들자 검이 일곱 자루로 분신! 일곱 번의 연속 베기(6-11) → 곰이 황금 동전 더미로 변해 무너짐(11-13) → 만화 로고 컷 "매직스플릿"(13-15)
- **카피:** "혼자 싸우지 마라. **일곱 번에 나눠 베어라.**"
- **사운드:** 오케스트라 + 록 기타, 소년만화 성우 톤
- **노리는 효과:** 웹툰/애니 세대(2030 남성) 타겟, 커뮤니티 화제성

## 5안. 「긴급속보」 — 가짜 뉴스 스튜디오 패러디
- **장르/톤:** 9시 뉴스 완벽 재현 페이크 포맷
- **비주얼:** 뉴스 스튜디오, 속보 자막바, 기자 중계 화면 분할
- **15초 흐름:** "긴급속보" 효과음, 앵커 긴박하게(0-2) → "속보입니다. 전국의 개미들이… 낮잠을 자고 있습니다"(2-6) → 현장 기자: 공원 벤치에서 꿀잠 자는 직장인, 폰에는 수익 알림 7개(6-11) → 앵커: "원인은 자동 분할매매로 밝혀졌습니다"(11-13) → 속보 자막바가 로고로 변환(13-15)
- **카피:** "개미가 잠들어도, 매매는 깨어있다"
- **사운드:** 실제 뉴스 시그널풍 브라스
- **노리는 효과:** 첫 2초 시선 강탈(뉴스로 오인), 전 연령 이해도 높음
- **주의:** 실제 방송사 로고·시그널 모방 금지, "광고" 표기 필수

## 6안. 「1929 무성영화」 — 흑백 슬랩스틱
- **장르/톤:** 찰리 채플린풍 무성영화. 유일한 흑백·무대사 안
- **비주얼:** 4:3 흑백, 필름 노이즈, 16fps 과장 움직임, 자막 카드
- **15초 흐름:** 중절모 신사가 차트 폭락에 기절, 과장된 쓰러짐(0-3) → 자막 카드: "全財産을 한 番에 걸었다가…"(3-5) → 마법사 등장, 지팡이 휘두르자 지폐 한 장이 일곱 장으로(5-9) → 신사, 일곱 장을 차례로 투자하며 점프 환호(9-12) → 자막 카드: "나눠라, 그러면 웃으리라" → 컬러로 전환되며 로고(12-15)
- **카피(자막 카드):** "百年 전에도 眞理였다 — 분할매매"
- **사운드:** 올드 피아노 래그타임
- **노리는 효과:** 광고 홍수 속 이질감으로 시선 고정, 아트 필름 감성. 칸 광고제 스타일

## 7안. 「수익 알림 ASMR」 — 사운드 중심 감각 광고
- **장르/톤:** ASMR / 오디오 퍼스트. 유일하게 '소리'가 주인공인 안
- **비주얼:** 매크로 초접사 — 폰 화면의 픽셀, 손끝 터치, 입술 클로즈업. 검은 배경
- **15초 흐름:** 속삭임: "들려요…?"(0-2) → 손끝이 화면을 톡. "매수 1차… 체결"(바이노럴 '톡' 사운드)(2-5) → 띠링… 띠링… 수익 알림음이 왼쪽 귀→오른쪽 귀로 7번 교차(5-11) → 속삭임: "일곱 번의 기분 좋은 소리"(11-13) → 알림음이 멜로디가 되어 로고 징글로(13-15)
- **카피:** "수익엔, 소리가 있다"
- **사운드:** 바이노럴 녹음, 화이트노이즈 베이스 — 이어폰 시청 유도 자막
- **노리는 효과:** 유튜브 프리롤 이탈 방지(소리 끄면 아까운 광고), 반복 시청

## 8안. 「2077 오토파일럿」 — SF 테크 시네마
- **장르/톤:** 애플/테슬라풍 미니멀 SF. 차갑고 미래적인 유일한 테크 안
- **비주얼:** 칠흑 공간 + 네온 홀로그램 UI, 슬로모션, 수트 입은 파일럿
- **15초 흐름:** 우주선 콕핏, 경보음 — 소행성(폭락 캔들)군 접근(0-4) → 파일럿이 버튼 하나 누름: "AUTO-SPLIT ENGAGED"(4-6) → 기체가 일곱 대의 드론으로 분리되어 각자 항로로 회피 기동, 소행성 사이를 유영(6-12) → 일곱 드론이 재결합, 금빛 항적(12-13) → 로고: "투자의 오토파일럿"(13-15)
- **카피:** "손은 떼고, 원칙은 켜라"
- **사운드:** 신스웨이브, 묵직한 저음 SFX
- **노리는 효과:** 자동매매의 '기술 신뢰감' 소구. 테크 얼리어답터·3040 남성

## 9안. 「점심시간 몰카」 — 리얼 관찰 예능 포맷
- **장르/톤:** 핸드헬드 몰래카메라 / 오피스 관찰 예능. 유일한 '리얼 날것' 안
- **비주얼:** 흔들리는 핸드헬드, 줌 당기기, 예능 자막·효과음, 모자이크 연출
- **15초 흐름:** 구내식당, 다들 폰 붙잡고 조마조마 차트 보는데(0-4) → 한 명만 여유롭게 돈가스 흡입. 동료가 수군: "쟤 뭐야?"(4-8) → 그 순간 그의 폰에서 띠링! 띠링! 알림 연타, 식당 전체가 뒤돌아봄(8-12) → 그가 씩 웃으며 한마디: "전 밥 먹을 때 폰 안 봐요"(12-13) → 예능 자막 "밥상 뒤집개 등장" + 로고(13-15)
- **카피:** "차트는 시스템이 보고, 당신은 돈가스를 보라"
- **사운드:** 예능 효과음(두둥, 띠용), 현장음
- **노리는 효과:** 직장인 공감 극대화, 숏폼 재편집 최적

## 10안. 「7개의 문」 — 초현실 아트 필름
- **장르/톤:** 미장센 중심 초현실주의(웨스 앤더슨 × 르네 마그리트). 유일한 아트/대칭 안
- **비주얼:** 파스텔 대칭 구도, 정면 고정 카메라, 느린 돌리인
- **15초 흐름:** 파스텔 복도에 일곱 개의 문이 정확히 대칭으로(0-3) → 정장 차림 인물이 첫 번째 문을 열면 작은 황금 동전 하나가 떠 있음(3-6) → 문들이 차례로 저절로 열리며 각 방의 동전이 하나씩 켜지듯 빛남 — 리드미컬한 "딸깍, 딸깍"(6-11) → 일곱 번째 문이 열리자 방 안이 온통 금빛(11-13) → 인물이 카메라를 정면으로 보며 살짝 목례, 로고(13-15)
- **카피:** "기회는 한 번에 오지 않는다. **일곱 번에 나눠서 온다.**"
- **사운드:** 하프시코드 + 메트로놈 딸깍 소리의 미니멀 리듬
- **노리는 효과:** 세련된 브랜드 이미지, 광고제·아트 감성층, 인스타그램 최적

## 공통 필수 사항 (전 안 적용)
1. **금융광고 심의:** 금융투자협회 광고 심의 필수. 원금 손실 가능성·"자동매매는 수익을 보장하지 않습니다" 고지 자막을 13-15초 구간에 삽입.
2. **무료 조건 표기:** "7종목×7차수 무료"는 유진투자증권 온라인 계좌 고객 한정임을 자막 고지.
3. **타 광고 모방 범위:** 레퍼런스의 '문법'만 차용하고 카피·비주얼·음원은 전부 오리지널 제작 (저작권/부정경쟁 방지).
4. **산출물:** 각 안당 16:9 15초(TV/유튜브) + 9:16 세로(숏폼) + 6초 범퍼 컷다운.

## 운영 제안
- 10종 전부 제작하는 대신, **디지털 A/B 테스트용 3종 선발**(예: 1안 밈형 + 2안 신뢰형 + 9안 공감형)을 먼저 제작→ 유튜브 성과(조회 유지율·클릭률) 상위 1종을 TV 집행하는 2단계 전략 권장.
