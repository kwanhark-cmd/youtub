## 개인비서 앱 (다섯 앱 통합)

이 저장소에는 다섯 앱(채널 관리·AI 대화 기록·하드 자료 찾기·물건 비우기·계정 구독 금고)을 하나로 합친 앱 **"개인비서"** 도 들어 있어요.

- 사용 설명: [`docs/개인비서_사용법.md`](docs/개인비서_사용법.md)
- 최종 보고: [`docs/보고/최종보고.md`](docs/보고/최종보고.md)
- 코드: `apps/assistant`(본체), `packages/`(공통·모듈), `modules_src/harddisk`(하드 엔진)
- 설치 파일: 이 저장소 **Releases** (또는 Actions → 가장 최근 "개인비서 검사와 빌드" → Artifacts)

## 사진 메타지우개 (중고거래용 독립 앱)

당근마켓·번개장터 거래 때 쓰는 사진 개인정보 보호 앱입니다.

- **지우기(판매)**: 사진의 위치(GPS)·날짜·기기 정보 등 메타데이터를 무손실로 지운 깨끗한 사본을 만들어 카톡·문자로 공유
- **기록(구매)**: 받은 사진에 날짜·물건 이름·메모·장소를 메타데이터로 새겨 "중고거래 기록" 앨범에 보관
- 사용 설명: [`docs/사진메타지우개_사용법.md`](docs/사진메타지우개_사용법.md)
- 코드: `apps/photoclean` · 설치 파일: Actions → "사진 메타지우개 검사와 빌드" → Artifacts
