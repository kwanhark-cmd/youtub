# 개인비서 사용법

다섯 앱을 하나로 합치고 **메타지우개 플러스**까지 넣은 앱이에요. **한 번 로그인**하면 채널 관리·AI 대화 기록·하드 자료 찾기·물건 비우기·계정 구독 금고·메타지우개 플러스(사진·문서 메타데이터 지우기)를 모두 쓸 수 있어요.

## 1. 설치
설치 파일은 공개 내려받기 페이지에 있어요. 로그인 없이 받을 수 있어요.

- 내려받기 페이지: <https://github.com/kwanhark-cmd/youtub/releases/latest>
- 바로 받기 (첫 공개 버전이 올라간 뒤부터 열려요):
  [안드로이드](https://github.com/kwanhark-cmd/youtub/releases/latest/download/gaein-biseo-android.apk) ·
  [윈도우](https://github.com/kwanhark-cmd/youtub/releases/latest/download/gaein-biseo-windows.zip) ·
  [맥](https://github.com/kwanhark-cmd/youtub/releases/latest/download/gaein-biseo-macos.zip) ·
  [리눅스](https://github.com/kwanhark-cmd/youtub/releases/latest/download/gaein-biseo-linux.tar.gz)

| 기기 | 파일 | 설치 |
|---|---|---|
| 안드로이드 | `gaein-biseo-android.apk` | 휴대폰에서 눌러 설치 ("출처를 알 수 없는 앱" 허용) |
| 윈도우 | `gaein-biseo-windows.zip` | 압축을 풀고 `personal_assistant.exe` 실행 ("Windows의 PC 보호" 창이 나오면 **추가 정보 → 실행**) |
| 맥 | `gaein-biseo-macos.zip` | 압축을 풀고 앱을 "응용 프로그램"으로 옮겨요. 처음 열 때 "열 수 없음" 안내가 나오면 **시스템 설정 → 개인정보 보호 및 보안 → 아래쪽 "그래도 열기"** (예전 macOS 는 **오른쪽 클릭 → 열기**) |
| 리눅스 | `gaein-biseo-linux.tar.gz` | 압축을 풀고 `bundle/personal_assistant` 실행 |

> 아이폰은 아직 준비 중이에요(설정만 들어 있어요).

### 새 버전으로 바꾸기
설정 맨 위 **업데이트 확인**을 누르면 새 버전이 있는지 알려 주고, 받을 곳을 열어 줘요. 앱이 스스로 설치하지는 않아요.
앱에는 서명 열쇠를 따로 두지 않아서, 안드로이드는 기존 앱 위에 덮어 설치가 안 돼요. 그래서 기기마다 방법이 달라요.

**안드로이드 — 꼭 이 순서대로** (기존 앱을 지우면 앱 안 자료도 함께 지워져요)
1. **먼저 백업**: 금고·대화·비우기·채널 모듈의 설정에서 각각 백업 파일을 만들어요. 저장 창이 뜨면 **다운로드** 폴더(또는 구글 드라이브·내 메일)처럼 **앱 밖**을 고르세요. 백업 비밀번호도 적어 두세요.
   - 대화: 설정 → "백업 파일 만들기" · 비우기: 설정 → 자료 관리 → "백업 파일 만들기"
   - 채널: 설정 → 자료 관리 → "백업 만들기" · 금고: 설정 → "백업 만들기·파일 불러오기(복원)" → "백업 파일 만들기" (공유 창이 뜨면 드라이브·메일·"파일에 저장" 중에서 골라요)
   - "앱 안에만 있어요" 안내가 나오면 저장이 안 된 거예요. 다시 눌러 앱 밖을 골라 주세요.
2. 새 설치 파일 `gaein-biseo-android.apk` 를 받아요 (업데이트 창의 **설치 파일 받기** 또는 위 링크).
3. 기존 개인비서 앱을 지워요. (로그인·열쇠·하드 연결 번호도 함께 지워져요)
4. 받은 파일을 눌러 설치해요.
5. 새로 로그인한 뒤 각 모듈 설정에서 되살려요.
   - 대화·비우기: "백업에서 되살리기" · 채널: "백업에서 복원"
   - 금고: 먼저 아무 비밀번호로 새 금고를 하나 만든 뒤, 설정 → "백업 만들기·파일 불러오기(복원)" → "백업 파일 불러오기(복원)" → 백업을 만들 때의 마스터 비밀번호로 열어요.
   - **설정 → 연결 상태 → 열쇠 넣기**에서 구글 열쇠(JSON)·AI 열쇠를, 하드 화면에서 연결 번호를 다시 넣어요.

**윈도우·맥·리눅스** — 새 파일을 받아 기존 앱을 새 것으로 바꿔요. 윈도우·리눅스는 압축을 풀어 기존 폴더를 새 폴더로 바꾸고, 맥은 응용 프로그램 폴더의 개인비서를 새 앱으로 바꿔요. 내 자료는 앱 폴더가 아니라 사용자 폴더에 있어서 그대로 남아요. (바꾸기 전에 백업 파일을 만들어 두면 더 안심이에요.)

## 2. 처음 쓸 때
1. 이름과 비밀번호(4자 이상)를 정합니다. "다음부터 자동으로 들어가기"를 켜 두면 편해요.
2. 따로 쓰던 앱이 있으면 **설정 → 기존 앱에서 가져오기**를 누르세요.
   - 컴퓨터(윈도우·맥·리눅스): 같은 컴퓨터의 단독 앱 자료를 찾아 **복사**해 와요. 원본은 그대로예요.
   - 금고는 **기존 마스터 비밀번호**로 그대로 열려요.
   - AI 대화 기록은 암호 열쇠가 기기 보안 저장소에 있어 바로 복사가 안 될 수 있어요. 그때는 단독 앱에서 "백업 만들기" → 개인비서의 대화 모듈에서 "백업에서 되살리기".
   - 안드로이드는 다른 앱 자료를 읽을 수 없어요. 각 단독 앱에서 백업 파일을 만들어 앱 밖(다운로드 등)에 저장하고, 개인비서의 해당 모듈 설정에서 되살리기(복원)를 해 주세요.
3. **설정 → 연결 상태 → 열쇠 넣기**에서 구글 열쇠(JSON 파일 하나)와 AI 열쇠 하나를 넣으면 모든 모듈이 같이 써요.

## 3. 홈
- 맨 위: 오늘 가장 먼저 할 일 하나를 크게, 나머지는 작게.
- 검색창: 다섯 곳(영상·대화·파일·물건·구독)을 한 번에 찾아요. 비밀번호는 절대 나오지 않아요.
- 색 타일 여섯 개: 누르면 그 모듈의 원래 화면이 열려요. 여섯 번째(청록색)가 **메타지우개 플러스**예요. 위쪽 띠의 **뒤로**·**개인비서**(홈) 버튼은 어느 모듈에서나 같은 자리예요.
- **말로 하기**: "아침 브리핑", "이번 주 조회수", "지난달 유튜브 앱 얘기한 대화", "2005년 아이들 영상", "힉스필드 언제 끝나". 애매하면 두 버튼으로 물어봐요. 업로드·삭제·공개·폐기는 실행 전에 한 번 더 확인해요. 마이크가 없으면 글자로 적으면 돼요.

## 4. 모듈 사이 연결 (제안함)
모듈끼리 쓸 만한 소재를 **제안**만 하고, **받기**는 직접 눌러요. 자동으로 올리거나 지우는 일은 없어요.
- 비우기 → 채널: 물건 사진·사연, 타임랩스 영상을 "내 코너" 소재로
- 하드 → 채널: 오늘의 추억(N년 전 오늘)
- 비우기 → 하드: "디지털로 남기고 버리기" 기록을 개인 기록 타임라인에
- 하드 → 금고: 영수증·계약서를 구독 근거 문서 후보로
- 대화 → 모든 모듈: AI 대화에서 찾은 결정 사항을 메모로
- 금고 → 채널: 채널 도구 비밀번호가 필요할 때, 내가 허락하면 금고에서 불러오기
설정의 "모듈 사이 연결"에서 하나씩 켜고 끌 수 있어요.

## 5. 메타지우개 플러스 (사진·문서 메타데이터)
중고거래 때 사진·문서에 숨은 개인정보(위치·날짜·기기·작성자 등)를 지우거나 일부만 고치는 모듈이에요. 단독 앱 "메타지우개 플러스"와 **똑같은 네 탭**이 그대로 들어 있어요.
홈의 청록색 **메타지우개 플러스** 타일을 누르거나, 말로 "메타지우개 열어 줘", "사진 위치 정보 지워 줘"라고 하면 열려요. (지우기·저장은 화면에서 직접 눌러요)

| 탭 | 하는 일 |
|---|---|
| **사진 지우기** | 사진 메타데이터를 전부 지운 사본 → 카톡·문자로 보내기 / 갤러리 "메타지우개" 앨범에 저장 |
| **사진 수정** | 날짜·위치·촬영 기기 중 고른 것만 바꾸거나 지우기 (설명·태그도 적을 수 있어요) |
| **문서** | PDF·한글(hwp·hwpx)·워드(docx·doc) 메타데이터 전부 지우기 또는 제목·작성자·만든 프로그램·날짜만 고치기 → 보내기·다른 이름으로 저장 |
| **구매 기록** | 받은 사진에 날짜·물건·메모·장소를 새겨 갤러리 "중고거래 기록" 앨범에 보관 |

- 원본은 건드리지 않고 사본을 만들어요. 사진·문서는 기기 안에서만 처리하고 어디에도 보내지 않아요.
- 개인비서 안에서는 메타지우개의 **새 버전 띠와 ⓘ(앱 정보·업데이트) 단추가 없어요.** 새 버전 확인도 하지 않아요. 업데이트는 개인비서 **설정 → 업데이트 확인** 하나로 해요.
- 따로 저장해 두는 자료가 없어서 백업·되살리기·가져오기가 필요 없어요. 만든 사진은 갤러리 앨범에 남아 앱을 지워도 그대로예요.
- 휴대폰(안드로이드)에서 쓰는 것이 기본이에요. 컴퓨터에서도 열리지만 "갤러리에 저장"은 기기에 따라 안 될 수 있어요(그때는 보내기·다른 이름으로 저장을 쓰세요).
- 기능 하나하나의 자세한 설명: [`메타지우개플러스_사용법.md`](메타지우개플러스_사용법.md)

## 6. 하드 자료 찾기
윈도우 PC에 **하드 자료 찾기 비서**(3번 앱 엔진)가 켜져 있어야 해요.
- 같은 PC: 그대로 열면 돼요.
- 휴대폰: PC 화면 "설정 → 다른 기기에서 보기"의 주소와 6자리 번호를 개인비서 하드 화면에 적어 주세요.
- 안드로이드·맥은 앱 안에서, 윈도우·리눅스는 인터넷 창(브라우저)으로 열려요.

## 7. 단독 앱은 계속 써도 되나요?
네. 단독 앱 다섯 개와 메타지우개 플러스는 그대로 써도 돼요. (메타지우개는 저장해 두는 자료가 없어 어느 쪽을 써도 같아요) 다만 **통합 앱과 자료는 따로**예요(앱 식별자가 달라 자료 폴더가 다름). 한쪽에서 바꾼 것이 다른 쪽에 저절로 반영되지 않으니, 옮겨 온 뒤에는 개인비서 하나만 쓰는 것을 권해요.

## 8. 문제가 생기면
설정 맨 위 **문제 신고** → 최근 기록 파일이 만들어져요(비밀번호·열쇠는 가려져 있어요).
