# 메타지우개 플러스 — 사용설명서 · 기능설명서

중고거래(당근마켓·번개장터)에서 사진과 문서를 주고받을 때 **숨은 개인정보(메타데이터)** 를 지우거나 일부만 고치는 앱입니다.
기존 "사진 메타지우개"(`apps/photoclean`)는 그대로 두고, 그 기능을 모두 포함해 새로 만든 별도 앱입니다. 코드는 `apps/metaclean`에 있고, 두 앱은 한 폰에 함께 설치할 수 있습니다.

> 통합 앱 **개인비서**(1.1.0부터) 안에도 같은 네 탭이 모듈로 들어 있습니다(홈의 청록색 "메타지우개 플러스" 타일). 개인비서 안에서는 아래 "2. 설치와 업데이트"의 새 버전 띠·ⓘ 단추가 없고, 업데이트는 개인비서 설정에서 합니다. → [`개인비서_사용법.md`](개인비서_사용법.md) 5장

## 1. 한눈에 보기

| 탭 | 언제 쓰나 | 하는 일 |
|---|---|---|
| **사진 지우기** | 물건 사진을 구매자에게 보낼 때 | 사진 속 메타데이터를 **전부** 지운 사본 만들기 |
| **사진 수정** *(새 기능)* | 전부 지우긴 싫고 일부만 바꾸고 싶을 때 | **날짜 · 위치 · 촬영 기기** 중 고른 것만 바꾸거나 지우기 |
| **문서** *(새 기능)* | 사용설명서·보증서 같은 문서를 함께 보낼 때 | PDF·한글·워드 문서의 메타데이터를 **전부 지우기** 또는 **일부만 고치기** |
| **구매 기록** | 판매자에게 받은 사진을 보관할 때 | 받은 날짜·물건 이름·메모·장소를 사진에 새겨 보관 |

모든 기능은 **원본을 건드리지 않고 사본을 새로 만듭니다.** 사진·문서는 폰 안에서만 처리하고 어디에도 보내지 않습니다. 인터넷은 **새 버전이 나왔는지 확인할 때만** 씁니다(작은 안내 파일 하나를 읽을 뿐, 사진·문서·기기 정보는 보내지 않습니다).

## 2. 설치와 업데이트

준비할 것이 없습니다. 열쇠 등록이나 로그인 없이, **어느 폰에서나 같은 주소에서 받아 설치**하면 됩니다.

### 2-1. 설치 (처음 설치 · 다른 폰에 설치)
1. 폰의 인터넷 창에서 아래 주소를 엽니다. (주소는 늘 같습니다)
   `https://github.com/kwanhark-cmd/youtub/releases/tag/metaclean-latest`
2. **metaclean-plus.apk** 를 눌러 내려받습니다.
3. 받은 파일을 열어 **설치**를 누릅니다. ("출처를 알 수 없는 앱" 허용 필요)

다른 폰에 깔 때도 똑같이 하면 됩니다. 폰마다 따로 등록하거나 준비할 것이 없습니다.

### 2-2. 새 버전으로 바꾸기 (기존 앱을 지우고 설치)
새 버전이 나오면 앱을 켰을 때 화면 위에 **"새 버전이 나왔어요 [받기]"** 띠가 뜹니다.

1. **[받기] → [새 버전 받기]** 를 눌러 설치 파일을 내려받습니다. (파일 이름에 번호가 붙습니다. 예: `metaclean-plus-15.apk`)
2. **지금 깔려 있는 앱을 지웁니다.** (앱 아이콘을 길게 누르고 [설치 삭제])
3. 내려받은 파일을 열고 **설치**를 누릅니다.

- **기존 앱을 지우지 않으면 설치되지 않습니다.** ("앱이 설치되지 않았습니다"라고 나오면 기존 앱을 지우고 다시 설치하세요.)
- 갤러리에 저장한 사진(메타지우개 앨범, 중고거래 기록 앨범)은 앱을 지워도 그대로 남습니다.
- 내려받기 폴더에 설치 파일이 여러 개 있으면 **번호가 가장 큰 파일**을 여세요. 설치한 뒤에는 내려받은 파일을 지워도 됩니다.
- 직접 확인하려면 화면 오른쪽 위 **ⓘ(앱 정보·업데이트)** 를 누릅니다. 버전은 `2.3.0 (빌드 15)` 처럼 표시되고, **빌드 번호가 큰 것이 새 버전**입니다.
- ⓘ 창에 "아직 올라온 새 버전이 없어요"라고 나오면 배포된 새 버전이 없다는 뜻이고, "확인하지 못했어요"라고 나오면 인터넷 연결을 확인하면 됩니다.

### 2-3. 왜 지우고 설치하나요? (참고)
안드로이드는 **같은 서명 열쇠로 만든 설치 파일만** 기존 앱 위에 덮어 설치해 줍니다. 덮어 설치를 하려면 서명 열쇠를 따로 만들어 보관·등록해야 하는데, 그 절차가 번거로워서 이 앱은 **열쇠를 두지 않는 쪽**을 골랐습니다. 대신 설치 파일은 만들 때마다 임시 열쇠로 서명되므로, 새 버전은 기존 앱을 지운 뒤 설치합니다.

**개발 메모**
- 설치 파일은 GitHub Actions("메타지우개 플러스 검사와 빌드")가 만들고, 테스트를 통과하면 위 고정 주소(Releases `metaclean-latest`)에 자동으로 올립니다. Secrets 는 쓰지 않습니다.
- 이미 올라간 버전의 내용을 모두 담은 커밋만 새 버전으로 올립니다. 옛 커밋에서 갈라진 다른 작업 가지는 빌드는 되지만 올라가지 않습니다(`main` 은 예외). 꼭 올려야 하면 워크플로를 `publish_anyway` 를 켜고 직접 실행합니다.
- 같은 가지에 푸시가 연달아 오면 가장 새 것만 빌드합니다.

## 3. 사용 방법

### 3-1. 사진 지우기 (전부 삭제)
1. "사진 고르기"로 여러 장 선택(앱 안의 사진 고르기 화면 — 아래 3-2-0 참고) → 자동으로 깨끗한 사본이 만들어집니다.
2. "메타데이터 32개 → 0개"처럼 결과를 확인하고 **"카톡·문자로 보내기"**.

지우는 것: 촬영 위치(GPS), 날짜, 기기 정보, 편집 기록(XMP), 갤럭시 모션포토에 숨은 동영상. JPEG·PNG는 화질 손실 없이 처리합니다.

### 3-2. 사진 수정 (일부만 바꾸기)
1. 바꿀 항목을 고릅니다. 항목마다 **그대로 / 지우기 / 바꾸기** 중 하나를 고릅니다.
   - **촬영 날짜**: 바꾸기를 고르면 날짜·시각을 선택합니다.
   - **촬영 위치**: 바꾸기를 고르면 좌표(예: `37.2954, 127.1518`)나 구글 지도의 플러스코드(예: `75W2+4PV 용인시 경기도`)를 그대로 붙여 넣습니다. 짧은 플러스코드는 뒤에 도시 이름이 있어야 풀 수 있습니다.
   - **촬영 기기**: 바꾸기를 고르면 **지금 쓰는 폰의 제조사·기종이 자동으로 입력**됩니다. 다른 기기로 적고 싶으면 고쳐 쓰면 되고, "이 폰 정보로 채우기"를 누르면 다시 이 폰 정보로 돌아갑니다.
   - **설명(선택)**: 제목·설명·태그를 적어 두면 나중에 사진을 찾기 쉽습니다. 한글도 그대로 저장됩니다.
2. "사진 고르고 수정하기" → 결과 목록에서 실제로 들어간 값을 확인 → 보내기 또는 갤러리 저장.

**"그대로"를 골랐는데 정보가 안 보일 때**: 원본 사진에 그 정보가 처음부터 없던 경우입니다(예: 이미 "사진 지우기"를 한 사진, 메신저로 받은 사진). 이때는 결과에 "없음(원본에도 없음)"이라고 표시됩니다. 정보를 새로 넣으려면 "바꾸기"를 고르세요.

고르지 않은 정보(조리개·노출 등 촬영 설정)와 화질은 그대로입니다. 다만 원래 날짜·위치가 다른 곳에 중복으로 남아 새어 나가지 않도록, 부가 정보(XMP)와 모션포토 동영상은 항상 함께 지웁니다. 기기를 지우거나 바꿀 때는 일련번호·렌즈 정보·제조사 전용 기록도 함께 지웁니다.

### 3-2-0. 사진 고르기 화면과 위치(지도)가 사라졌던 이유 (2.3.2)

**무슨 일이 있었나**: 갤러리에서는 지도(예: 용인시)가 보이는 사진인데, "사진 수정"에서 날짜만 바꾸고 위치는 **그대로**로 두었더니 결과 사진에 위치가 없었습니다(날짜·기기는 그대로). 앱이 위치를 지운 것이 아니라, **안드로이드가 사진을 앱에 넘겨줄 때 위치 값을 0으로 덮어서** 넘겨준 것입니다. 안드로이드 10부터는 폰의 사진을 볼 권한이 없는 앱에 사진을 넘길 때 촬영 위치를 가립니다. 2.3.1은 시스템 "파일" 고르기 창으로 바꿔 이를 피하려 했지만, 삼성 갤럭시(One UI) 등에서는 고르는 도중 시스템 사진 고르기 창("사진 / 컬렉션")이나 "내 파일" 앱이 끼어들어 **여전히 위치가 가려진 사진**이 왔습니다. 어느 창이 뜨는지는 폰마다 다릅니다.

**2.3.2에서 바뀐 것 (안드로이드)**: 시스템 고르기 창을 쓰지 않고, **앱 안의 사진 고르기 화면**에서 폰의 사진 보관함을 직접 읽습니다. 안드로이드가 정해 둔 "원본 그대로 읽기" 방법(사진 보기 권한 + 사진 위치 정보 접근 권한 + 원본 요청)이라 폰 기종과 상관없이 위치까지 옵니다.

1. "사진 고르기"(또는 "사진 고르고 수정하기", "받은 사진 고르기")를 누르면 **사진 고르기** 화면이 열립니다.
2. 처음에는 **"사진을 보려면 허용이 필요해요"** 설명이 나옵니다. **사진 보기 허용하기** → 안드로이드 창에서 **"모두 허용"** 을 누르세요. 위치 정보 접근을 묻는 창이 뜨면 그것도 허용합니다. 사진은 이 폰 안에서만 읽고 어디로도 보내지 않으며, 지금 내가 있는 곳을 알아내지 않습니다.
3. 최근 사진이 격자로 보입니다. 위쪽의 앨범 이름(예: "최근 사진 (1234)")을 눌러 **Camera** 같은 다른 앨범으로 바꿀 수 있습니다.
4. 사진을 누르면 고른 순서대로 번호가 붙고, 다시 누르면 빠집니다. 아래에 **"N장 골랐어요"** 가 보입니다. (구매 기록은 한 장만)
5. 아래의 큰 단추 **"고른 사진 N장 쓰기"**(한 장이면 "이 사진 쓰기")를 누릅니다.

**"일부 사진만 허용"을 골랐다면** (안드로이드 14 이상): 고른 몇 장만 보이고, 화면 위에 **"⚠️ 일부 사진만 허용돼 있어요"** 안내가 뜹니다. 이 상태에서는 안드로이드가 위치를 가릴 수 있으니, **설정 열기** → 권한 → 사진 및 동영상 → **모두 허용**으로 바꾸세요. "보여 줄 사진 더 고르기"로 보이는 사진을 늘릴 수도 있고, 지금 보이는 사진으로 그냥 계속해도 됩니다(위치가 가려지면 결과에 알려 줍니다).

**허용하지 않았다면**: 같은 설명 화면에 **설정 열기**와 **"허용했어요"**(설정에서 허용하고 돌아왔을 때) 단추가 있습니다. 끝까지 허용하고 싶지 않으면 맨 아래 **"파일 창에서 고르기"** 로 예전처럼 고를 수 있습니다. 다만 이때는 폰이 위치를 가리고 넘겨줄 수 있습니다.

아이폰 등 안드로이드가 아닌 기기는 예전처럼 사진 고르기 창을 씁니다.

**제대로 됐는지 확인**: 결과 목록에 실제 좌표가 보입니다.
- 사진 수정: **"위치 유지됨 (37.27, 127.15)"**(그대로), **"위치 바뀜 (35.10, 129.04)"**(바꾸기)
- 사진 지우기: **"위치정보(GPS) 제거됨 (원본 위치 37.27, 127.15)"**
- 구매 기록: 사진을 고르면 **"사진 속 위치: 37.27, 127.15"**

**"⚠️ 폰이 사진 N장을 위치 정보 없이 넘겨줬어요" 안내가 뜨면** (안전장치): 받은 사진에 위치 칸은 있는데 좌표가 비어 있다는 뜻입니다(안드로이드가 가려서 넘겨준 모양). 이때 앱은
- **사진 수정**: 위치 "그대로"를 지킬 수 없으므로 결과에 "위치 없음(폰이 위치를 가린 채 넘겨줌)"이라고 쓰고, 망가진 위치 칸은 결과에 넣지 않습니다.
- **사진 지우기**: 진짜 좌표가 있었을 때만 "위치정보(GPS) 제거됨"이라고 씁니다. 가려진 사진은 "원본 위치 확인 불가"라고 씁니다(만든 사본에는 위치가 없습니다).
- **구매 기록**: 위도·경도를 직접 적지 않으면 위치 없이 기록합니다.

고치는 법: 안내의 **"권한 허용하기"** 를 누릅니다. 안드로이드 창이 뜨면 "모두 허용", 창이 뜨지 않으면 알림 띠의 **설정 열기** → 권한 → 사진 및 동영상 → **모두 허용**(사진 위치 관련 항목이 따로 보이면 그것도 허용). 그다음 **사진을 다시 고르세요.**

**개발 메모**: 안드로이드에서는 photo_manager 부품으로 MediaStore 를 직접 읽습니다. 권한은 READ_MEDIA_IMAGES(13+)·READ_MEDIA_VISUAL_USER_SELECTED(14+)·READ_EXTERNAL_STORAGE(12 이하)·ACCESS_MEDIA_LOCATION 을 함께 받고, 원본은 `AssetEntity.originBytes` 로 읽습니다(ACCESS_MEDIA_LOCATION 이 있으면 `MediaStore.setRequireOriginal`). 단독 앱은 CI 의 "앱 이름·권한 설정" 단계가 매니페스트에 권한을 넣고, 개인비서는 AndroidManifest.xml 에 같은 값이 있습니다.

### 3-2-1. 파일 이름과 파일 날짜

폰 카메라는 사진 이름을 찍은 날짜로 짓습니다(예: `20261112_143000.jpg`). 그 이름을 그대로 쓰면 사진 속 날짜를 고치거나 지워도 이름에 옛 날짜가 남습니다. 그래서 앱은 결과 파일 이름을 이렇게 짓습니다.

| 한 일 | 결과 파일 이름 |
|---|---|
| 사진 수정에서 날짜를 **바꿈** | 바꾼 날짜로 지음 (예: `19800101_120000_3fa2c1.jpg`) |
| 사진 수정에서 날짜를 **지움**, 또는 사진 지우기 | 원본 이름을 쓰지 않고 새로 지음 (예: `사진_3fa2c1.jpg`) |
| 사진 수정에서 날짜를 **그대로** 둠 | 원본 이름을 이어 씀 (예: `20261112_143000_3fa2c1.jpg`) |

- 이름 끝의 여섯 글자(`3fa2c1`)는 **사진마다 다른 구분 표시**입니다. 시각이나 기기 정보가 아니고 사진 내용에서 뽑은 값이라, 같은 날짜로 바꾼 사진 여러 장이 서로 섞이거나 갤러리에서 이름이 제멋대로 바뀌는 일을 막아 줍니다.
- 날짜를 바꾸거나 지울 때는 옛 촬영 순간의 흔적(GPS 시각·날짜, 초 아래 자리, 제조사 전용 기록 MakerNote)도 함께 지웁니다. 제조사·기종 이름은 "촬영 기기"에서 고른 대로 남습니다.

**"파일 날짜(만든 날짜 / 수정한 날짜)"는 앱이 정할 수 없습니다.** 이 값은 사진 안에 든 것이 아니라, 파일이 그 폰이나 컴퓨터에 저장된 시각을 기기가 붙이는 것입니다. 갤러리에 저장하거나 카톡으로 보내면 그 순간의 시각으로 새로 붙습니다. 다만 **갤러리와 사진 앱은 사진 속 촬영 날짜를 기준으로 정렬·표시**하므로, 앱에서 바꾼 날짜가 그대로 보입니다. 맥의 Finder에서 보이는 파일 날짜까지 맞추고 싶으면 터미널에서 `touch -t 198001011200 ` 를 입력하고(연월일시분, 끝에 한 칸) 파일을 터미널 창에 끌어다 놓은 뒤 Enter를 누르면 됩니다.

### 3-3. 문서 (PDF · 한글 · 워드)
1. "문서 고르기" → 지금 들어 있는 정보(작성자, 회사, 만든 날짜, 만든 프로그램 등)를 보여 줍니다.
2. 방식을 고릅니다.
   - **전부 지우기**: 모든 메타데이터 삭제
   - **일부만 고치기**: 체크한 항목만 변경 — **제목 / 작성자 / 만든 프로그램·기기 / 날짜**. 체크하지 않은 항목은 그대로 둡니다.
3. "사본 만들기" → "사본에 남아 있는 정보"로 결과 확인 → **보내기** 또는 **내 폰에 저장**.

| 문서 종류 | 전부 지우기 | 일부 고치기 | 참고 |
|---|---|---|---|
| PDF | ✅ | ✅ | 문서 정보, 부가 정보(XMP), 삽입된 그림이 따로 가진 작성 정보, 편집 프로그램의 비공개 자료까지 지움. 암호 걸린 PDF는 불가 |
| 한글 hwpx | ✅ | ✅ (프로그램 항목 제외) | 압축 파일 안의 수정 시각 흔적도 통일 |
| 한글 hwp | ✅ | ✅ | 본문은 한 바이트도 건드리지 않음. 고친 글자가 문서의 여유 자리보다 길면 줄여서 넣고 알려 줌 |
| 워드 docx (엑셀 xlsx·파워포인트 pptx 포함) | ✅ | ✅ | 본문의 메모·변경 내용에 남은 작성자 이름도 처리 |
| 옛 워드 doc (xls·ppt 포함) | ✅ | ✅ (영문·숫자만) | 요약 정보만 처리. 더 꼼꼼히 하려면 docx로 저장 후 다시 |

### 3-3-1. 인화·현상 사진에 날짜 지정 (스캔/필름 사진 정리)

필름 카메라로 찍어 **인화·현상한 옛 사진**을 지금 폰으로 다시 촬영하면, 오늘 날짜의 메타데이터가 붙습니다. 이걸 그 사진의 **실제 날짜**로 바꾸면 갤러리에서 제 날짜에 정리됩니다. (애플 사진·구글 포토의 "날짜 조정"과 같은 표준 기능입니다.)

1. "사진 수정" 탭에서 **촬영 날짜 → 바꾸기** → 원하는 날짜 선택 (예: 1980-01-01)
2. 필요하면 **촬영 기기 → 바꾸기** → 자동으로 들어간 이 폰 정보를 지우고 필름 카메라 이름 입력 (예: Canon AE-1)
3. "사진 고르고 수정하기" → 사본 저장/공유

메타데이터가 전혀 없는 사진에도 새 EXIF가 만들어집니다. 이렇게 넣은 날짜·카메라는 **누구나 EXIF 뷰어로 확인하고 다시 고칠 수 있는 일반 메타데이터**입니다. (이 앱은 수정 사실을 감추거나 위조를 탐지 불가능하게 만드는 기능은 제공하지 않습니다.)

### 3-4. 구매 기록
받은 사진을 고르고 물건 이름(필수)·메모·날짜·장소·좌표를 적으면, 사진에 새겨 갤러리 "중고거래 기록" 앨범에 보관합니다.

## 4. 알아 둘 점 (한계)

- PDF 안의 **메모·주석을 단 사람 이름**, 문서 **본문에 직접 적힌 이름·날짜**는 메타데이터가 아니라 내용이므로 지우지 않습니다.
- 한글 hwp·옛 doc의 **변경 추적 기록 속 작성자**는 처리하지 않습니다.
- HEIC 사진은 지원하지 않습니다. (갤럭시 카메라 기본 설정은 JPEG입니다)
- PDF 처리에 쓰는 `syncfusion_flutter_pdf` 라이브러리는 개인·소규모 사업자에게 무료인 커뮤니티 라이선스 대상입니다. 사업 규모가 큰 곳에서 쓰려면 Syncfusion 라이선스 조건을 확인하세요.

## 5. 검증 방법 (개발 메모)

- 자동 테스트 35개: 사진(무손실 확인 포함), PDF·docx·hwpx·hwp 지우기/고치기, 작은 화면 배치.
- 한국 시간·세계 표준시 등 여러 시간대에서 테스트를 돌려 날짜가 어긋나지 않는지 확인.
- 실제 파일(LaTeX 논문 PDF, 오픈오피스 PDF, 워드 docx·doc, 실제 한글 hwp·hwpx)로 처리 후, 별도 도구(pikepdf·olefile·python-docx)로 다시 열어 ① 문서가 깨지지 않았는지 ② 본문이 원본과 같은지 ③ 옛 값이 파일 어디에도 남지 않았는지 확인. PDF는 화면에 그린 결과가 원본과 똑같은지도 비교.
