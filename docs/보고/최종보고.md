# 개인비서 통합 최종 보고

## 1. 통합된 것
| 모듈 | 원래 앱 | 통합 방식 | 홈에 보이는 것 |
|---|---|---|---|
| 채널 관리 | kwanhark-cmd/-(유튜브) | Flutter 패키지 그대로 | 확인 대기 영상, 오늘 게시 예정, 구글 연결 만료 |
| AI 대화 기록 | 2222 | Flutter 패키지 그대로 | 내보내기 요청할 때, 주제 없는 대화 |
| 하드 자료 찾기 | 3333 | 엔진·웹 화면 그대로, 본체에서 웹뷰(안드로이드·맥) / 브라우저(윈도우·리눅스) | 오늘의 추억 |
| 물건 비우기 | 4444 | Flutter 패키지 그대로 | 오늘 정할 물건, 가격 내리기 추천 |
| 계정·구독 금고 | 5555 | Flutter 패키지 그대로, 암호화 변경 없음 | 만료 임박 크레딧·결제 (금고가 열려 있을 때) |

공통(새로 만든 것): 한 번 로그인, 하나의 홈·오늘 할 일·검색창, 마이크 하나 음성 비서(규칙 기반 라우터, 애매하면 두 버튼, 중요 명령 확인, 비밀번호 읽기 거부), 아침 브리핑, 설정 하나(글씨 3단계·테마·고대비·움직임), 연결 상태 화면, 열쇠 하나(구글 JSON 하나 + AI 하나 → 각 모듈 빈 칸에만 전달), 기존 앱에서 가져오기, 업데이트 확인(누를 때만·해시 확인), 문제 신고(비밀 값 가림), 모듈 사이 제안함 6가지.

## 2. 단독 앱과 달라진 것
- 모듈 위에 같은 자리의 "뒤로"·"개인비서 홈" 띠가 생겼어요.
- 채널 모듈은 개인비서 로그인 이름으로 자동으로 들어가고 첫 안내를 건너뛰어요. 대화 모듈도 같은 이름으로 들어가요(잠금 번호가 있으면 그대로 물어봐요).
- 금고는 개인비서 로그인과 상관없이 항상 자기 마스터 비밀번호로 열어요.
- 음성으로 자료를 바꾸는 명령(업로드·폐기·해지 등)은 바로 실행하지 않고 해당 모듈 화면을 열어 직접 확인하게 해요.
- 모듈 자료는 통합 앱 사용자 폴더 아래 모듈별 폴더(channel_biseo, ai_chat_organizer, binugi, vault_app)에 있어요.

## 3. 검증
- 기존 테스트 통합 후 전부 통과: 채널 187, 대화 94, 비우기 168, 금고 128 (단독 앱 플랫폼 설정 파일 확인 5건은 통합 앱에서 건너뜀 → 통합 앱 식별자 시험으로 대체)
- 공통 16, 본체 49: 통합 흐름(로그인 → 홈 → 모듈 열기·뒤로·홈 → 음성 → 브리핑 → 애매 → 비밀번호 거부 → 통합 검색 → 제안 받기), 실패→다시 시도, 작은 화면·아주 큰 글씨·어두운·고대비 넘침 없음, 스크롤 유지, 모듈별 실제 자료 연결 시험
- ★ 금고 호환: 단독 금고 1.0.0 기준 파일을 "가져오기"로 옮긴 뒤 같은 마스터 비밀번호로 열리고 모든 항목 동일, 틀린 비밀번호 거절, 원본 불변
- 하드 엔진 파이썬 시험 통과, 실제 엔진에 연결해 상태·기록 추가 확인
- 리눅스 빌드·실행: 첫 화면 0.1~0.15초, 모듈 열기 채널 0.23초·대화 0.1초·비우기 0.56초·금고 0.03초 (모듈은 눌러야 화면을 만듦)
- GitHub Actions: 검사·테스트·리눅스·하드 엔진 통과. 안드로이드는 SDK 37로 고친 뒤 다시 실행 중, 윈도우·맥은 결과 확인 필요(PROGRESS.md 참고)

## 4. 못 한 것 (다음 세션)
- 5단계 화면 재설계를 모듈 안까지 통일 (본체 화면만 새 규칙 적용, 모듈은 각자 1.1.0 재설계 상태)
- 개인비서 글씨 크기·테마가 모듈 안에 바로 적용되는 것은 채널만 (다른 모듈은 첫 안내에서 고름)
- 안드로이드에서 "기존 앱 가져오기"는 다른 앱 자료를 읽을 수 없어 각 모듈의 백업→복원으로 안내
- 대화 모듈의 암호 열쇠가 기기 보안 저장소에만 있으면 복사 불가 → 백업·복원으로 안내
- 피그마 열쇠는 채널 모듈이 로그인 방식이라 열쇠 하나로 전달 불가
- 음성 확인 후 바로 실행(모듈 화면에서 확인하게 함), 6단계 앱별 항목, 아이폰 빌드, Releases 첫 배포(태그 v1.0.0 또는 Actions → Run workflow → release 체크)

## 5. 기존 앱에서 옮겨 오는 순서
1. 개인비서 설치 → 로그인(단독 채널 앱과 같은 이름 쓰면 편함)
2. 설정 → 기존 앱에서 가져오기 → 금고 → 비우기 → 채널 → 대화 순서로 "가져오기"
3. 금고 모듈을 열어 기존 마스터 비밀번호로 열리는지 확인
4. 설정 → 연결 상태 → 열쇠 넣기: 구글 JSON 하나, AI 열쇠 하나
5. 하드: PC 엔진 그대로 사용, 휴대폰이면 주소와 6자리 번호 입력

## 6. 단독 앱을 계속 써도 되나요?
네, 계속 써도 돼요. 단독 앱과 통합 앱은 **자료가 따로**예요(앱 식별자 com.kwanhark.personal_assistant 가 달라 자료 폴더·보안 저장소가 다름). 가져오기는 복사라서 원본은 그대로 남지만, 이후 한쪽에서 바꾼 내용이 다른 쪽에 반영되지 않으니 옮긴 뒤에는 개인비서 하나만 쓰는 것을 권해요.
