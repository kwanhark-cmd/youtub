# 사진 메타지우개 — 사용 설명서

중고거래(당근마켓·번개장터)용 사진 개인정보 보호 앱입니다. 코드는 `apps/photoclean`에 있습니다.

## 무엇을 하는 앱인가요?

| 탭 | 언제 쓰나 | 무엇을 하나 |
|---|---|---|
| **지우기 (판매)** | 내 물건 사진을 구매자에게 보낼 때 | 사진 속 모든 메타데이터(촬영 위치 GPS, 날짜, 기기 정보, 갤럭시 모션포토에 숨은 동영상까지)를 지운 **깨끗한 사본**을 만들어 카톡·문자로 공유 |
| **기록 (구매)** | 판매자에게 메타데이터 없는 사진을 받았을 때 | 받은 날짜(기본 오늘)·물건 이름·메모·거래 장소·위도/경도를 사진 메타데이터에 **새겨서** "중고거래 기록" 앨범에 보관 |

- 원본 사진은 절대 건드리지 않고 항상 **사본**을 만듭니다.
- 지우기는 JPEG·PNG에서 **무손실**(화질 저하 없음)로 동작합니다. 그 외 형식은 JPEG로 변환하며 지웁니다.
- 지운 뒤 "메타데이터 N개 → 0개"로 결과를 직접 확인시켜 줍니다.

## 설치 방법 (갤럭시)

1. 이 저장소의 **Actions → "사진 메타지우개 검사와 빌드" → 가장 최근 실행 → Artifacts**에서 `사진메타지우개-APK`를 받습니다.
2. 압축을 풀어 `app-release.apk`를 폰으로 옮긴 뒤 설치합니다. ("출처를 알 수 없는 앱" 허용 필요)

## 쓰는 순서 (판매할 때)

1. 앱을 열고 **지우기 (판매)** 탭 → "사진 고르기"
2. 물건 사진을 여러 장 선택하면 자동으로 깨끗한 사본이 만들어집니다
3. "카톡·문자로 보내기"를 누르면 안드로이드 공유 창이 떠서 카카오톡/메시지를 고를 수 있습니다

## 쓰는 순서 (구매할 때)

1. 받은 사진을 갤러리에 저장해 둡니다 (카톡에서 사진 길게 눌러 저장)
2. **기록 (구매)** 탭 → "받은 사진 고르기" → 물건 이름(필수), 메모·장소·좌표(선택) 입력
3. "기록 새겨서 보관하기"를 누르면 갤러리 "중고거래 기록" 앨범에 저장됩니다
4. 나중에 갤러리에서 사진 상세정보를 보면 기록한 날짜·설명이 보입니다

## 기술 메모

- 메타데이터 제거는 자체 구현한 무손실 스트리퍼(`lib/src/strip.dart`)가 JPEG의 APP1~APP15·COM 세그먼트와 PNG의 tEXt·eXIf 등 청크를 제거합니다. JPEG 끝(EOI) 뒤에 붙는 숨은 데이터(갤럭시 모션 포토 동영상)도 잘라냅니다.
- 기록은 순수 Dart(`image` 패키지)로 DateTimeOriginal·ImageDescription·GPS 좌표를 EXIF에 씁니다. 메타데이터 읽기는 `exif` 패키지(순수 Dart)를 씁니다. 네이티브 플러그인 의존이 없어 빌드가 안정적입니다.
- 안드로이드 플랫폼 폴더는 CI가 빌드 때마다 `flutter create`로 생성하므로 저장소에는 Dart 코드만 둡니다.
