# 막힌 것 (사용자가 해주면 되는 것)

작업 중 해결하지 못한 문제와, 사용자가 무엇을 해주면 되는지를 쉬운 말로 적습니다.

| # | 무엇이 안 됐나 | 사용자가 해줄 일 |
|---|----------------|------------------|
| 1 | 구글(유튜브·블로그) 실제 연결은 사용자 계정과 "구글 클라우드 프로젝트"가 있어야 해서, 개발 중에는 가짜 데이터(연습 모드)로만 확인했습니다. | README 의 "구글 연결 준비하기" 순서대로 클라이언트 ID 를 만들어 앱 설정에 넣어 주세요. |
| 2 | Claude(AI) 실제 호출은 비용이 들어 개발 중에는 하지 않았습니다. | 설정 → AI 연결에 API 키를 넣으면 바로 켜집니다. |
| 3 | 힉스필드 실제 API 의 주소·형식을 공식 문서로 확인하지 못해, 흔한 형식으로 만들어 두고 연습용 가짜로만 확인했습니다. | 힉스필드 키를 넣고 "연결 테스트"를 눌러 보세요. 실패하면 "문제 신고" 파일을 Claude에게 보여 주시면 주소를 맞춰 드립니다. |
| 4 | 피그마 연결은 피그마 개발자 앱(클라이언트 ID)이 있어야 해서 실제로는 확인하지 못했습니다. 돌아오는 주소는 `http://127.0.0.1:53682/callback` 으로 등록해야 합니다. | 피그마 개발자 설정에서 앱을 만들고 위 주소를 등록한 뒤 앱의 도구 연결 화면에 넣어 주세요. |
| 5 | 구글 비즈·브루는 공식 API 가 없어 첫 버전에서는 "준비 중" 으로만 표시합니다 (지시서대로). | 없음 |
| 6 | 안드로이드 업데이트(덮어쓰기 설치)는 모든 버전이 같은 서명 키여야 하는데, 서명 키 파일은 저장소에 넣으면 안 되어서 만들지 않았습니다. 지금 GitHub 가 만드는 안드로이드 파일은 매번 테스트용 서명입니다. | README "안드로이드 서명 키" 대로 키를 한 번 만들고 GitHub 비밀 값 4개를 넣어 주세요. 그 뒤로는 자동으로 같은 키로 만들어져 업데이트가 됩니다. (1.1.0 이하 안드로이드 앱은 한 번만 백업 → 지우고 새로 설치 → 되살리기) |
| 7 | 안드로이드 홈 화면 아이콘 바꾸기·바로가기·업데이트 설치 화면, 윈도우 설치 프로그램, 맥 앱 바꿔 끼우기는 이 개발 환경에서 실제 기기로 확인하지 못했습니다 (GitHub Actions 빌드로만 확인). | 새 버전을 설치해 써 보시고, 안 되면 "문제 신고" 파일을 보내 주세요. |
