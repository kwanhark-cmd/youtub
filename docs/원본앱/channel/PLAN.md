# 계획서 — 유튜브 블로그 채널 관리 비서

이 문서는 작업 지시서(자동 진행판)를 바탕으로 만든 개발 계획입니다. 승인 없이 바로 진행합니다.

## 큰 그림

- 앱 이름: **유튜브 블로그 채널 관리 비서**
- 기술: Flutter 한 코드로 안드로이드·윈도우·맥(·리눅스) 배포 (설치 실패 시 Electron+React / Capacitor 로 대체 — DECISIONS.md 참고)
- 데이터: 기기 안 SQLite (`sqlite3` 패키지), 민감 정보는 OS 보안 저장소(`flutter_secure_storage`)
- 외부 연결: 모두 "설정에서 나중에 입력" 구조. 키가 없으면 **연습 모드(목업)** 로 전체 흐름이 동작
- 안전 원칙: 실제 업로드·삭제·공개 전환은 코드가 자동으로 하지 않음. 업로드는 항상 비공개, 공개는 사용자가 유튜브에서 직접

## 작업 순서

### 0단계 — 뼈대
1. Flutter 설치, 프로젝트 생성, 한국어 글꼴 포함
2. 공통 기반: 한국어 문자열 파일, 오류 종류(토큰 만료/권한 취소/한도 초과/네트워크), 시간 제한·재시도, 민감정보 제거 로그, 전역 오류 처리
3. DB(버전 번호 + 자동 변환 + 변환 전 백업), 보안 저장소 추상화
4. 로컬 계정 로그인(여러 사용자, 데이터 분리), 첫 실행 마법사, 설정 화면(글씨 크기, 초기화 2번 확인, 백업·복원, 문제 신고, 버전·변경 내역, 아이폰 준비 중)
5. 음성 기능 틀(음성 인식·TTS 추상화, 명령 해석기)

### 1단계 — 유튜브 채널 관리
- 채널 등록(URL + 구글로 연결, OAuth PKCE, 토큰만 저장), 채널별 연결 해제
- 채널 현황(나눠 불러오기, 음성 요약), 유튜브 API 하루 한도 관리(남은 한도, 다음 날로 넘기기)
- 채널 스타일 카드(분석 + 수정)
- 기존 영상 자동 수정(원본 기록, 되돌리기, 채널당 하루 2~3개, 조회수 비교)
- 매일 수정 내역 요약(화면+음성), 아침 브리핑
- 자동 작업 실행기(기본 꺼짐, 시간대, 전후 알림, 진행률·취소)
- AI 연결(키, 예상 비용, 월 누적, 한도 → 자동 작업 중지, 연습 모드 표시)

### 2단계 — 콘텐츠 제작과 업로드
- 형식 선택(쇼츠/롱폼/다큐/이미지 게시물/음성 대화형), 제목·설명·키워드·썸네일 함께 제작
- 업로드 항상 비공개 + 확인 대기 목록, AI 콘텐츠 표시 방법 선택 + 업로드 전 확인
- 비슷한 콘텐츠 반복 방지, 하루 제작 한도
- 도구 연결 화면(힉스필드 키, 피그마 OAuth, 구글 비즈·브루 준비 중), 힉스필드는 사용자 승인 + 크레딧 표시, 직접 만든 영상 파일 넣기

### 3단계 — 블로그·티스토리
- Blogger API 글 분석·수정(원본 기록·되돌리기)·새 글 비공개(초안) 업로드
- 티스토리: 글 완성 + 복사 버튼(자동 게시 없음)

### 4단계 — 사용자 코너
- 코너 이름·채널 지정, 영상·음성 메모 → 자막·제목·설명·키워드·썸네일·여러 형식
- "폴더에서 소재 가져오기" 공통 인터페이스(3번·4번 앱 연동용)
- 저작권 의심 소재 사용 여부 확인
