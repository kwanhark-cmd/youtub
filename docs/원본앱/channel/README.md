# 유튜브 블로그 채널 관리 비서

여러 유튜브 채널과 구글 블로그·티스토리를 한곳에서 관리하고, 채널 스타일에 맞는 콘텐츠를 만들어 **비공개**로 올려 두면 사용자가 확인한 뒤 직접 공개하는 앱입니다.

- 윈도우·맥 컴퓨터, 안드로이드 휴대폰에서 쓸 수 있어요. (아이폰은 준비 중)
- 계정이나 AI 키가 없어도 **연습 모드**로 모든 기능을 미리 써 볼 수 있어요. 연습 모드에서는 실제 유튜브·블로그에 아무것도 바뀌지 않아요.
- 앱은 영상 **삭제**와 **공개 전환**을 절대 하지 않아요. 업로드는 항상 비공개이고, 공개는 사용자가 유튜브에서 직접 해요.

> 📷 = 이 자리에 화면 사진을 넣으면 좋은 곳입니다. (사진 파일은 `docs/사진/` 폴더에 넣고 이름만 바꿔 주세요)

---

## 1. 설치 파일 받기

> **새 버전 설치 = 앱 파일 덮어쓰기, 설정은 유지됨.**
> 설정·연결 열쇠·채널·영상·제작 자료는 앱 파일이 아닌 사용자 폴더와 운영체제 보안 저장소에 있어서, 새 버전을 덮어써도 그대로 남아요. 지우고 다시 설치할 필요가 없어요.

### 처음 설치
1. 이 저장소 페이지 오른쪽의 **Releases** (또는 주소 끝에 `/releases`)를 누릅니다.
2. 맨 위(가장 최근) 버전에서 내 기기에 맞는 파일을 내려받습니다.
   - 윈도우: `channel-biseo-windows-setup.exe` 실행 → 설치가 끝나면 시작 메뉴에 "채널관리비서"
   - 맥: `channel-biseo-macos.zip` 압축을 풀고 `channel_biseo.app` 을 응용 프로그램 폴더로 옮김
     (처음 열 때 "확인되지 않은 개발자" 경고가 나오면: 앱을 **오른쪽 클릭 → 열기**)
   - 안드로이드: `channel-biseo-android.apk` 를 휴대폰에서 열어 설치
     (설정에서 "출처를 알 수 없는 앱 설치" 를 허용해야 할 수 있어요)
   - 리눅스: `channel-biseo-linux.tar.gz` 압축을 풀고 `bundle/channel_biseo` 실행

아직 Releases 에 아무것도 없으면 **Actions → 빌드와 테스트 → 가장 최근 ✅ → Artifacts** 에서 받을 수 있어요.

📷 `docs/사진/01-actions-artifacts.png` — Actions 화면의 Artifacts 위치

### 새 버전으로 바꾸기 (업데이트)
- **앱 안에서**: 설정 맨 위 **"업데이트 확인"** → 새 버전이 있으면 바뀐 점을 보여 줘요 → **"설치하기"** 를 누를 때만 받아서 설치해요 (자동으로 받지 않아요).
  설치 전에 모든 자료를 `문서/채널관리비서/업데이트-백업/` 에 자동으로 백업해요.
  - 윈도우: 설치 프로그램이 같은 자리에 덮어쓰고 앱을 다시 열어요.
  - 맥: 앱이 닫히고 새 앱으로 바뀐 뒤 다시 열려요.
  - 안드로이드: 설치 화면이 열리면 **"업데이트"** 를 누르세요.
- **직접**: Releases 에서 새 파일을 받아 위 "처음 설치"와 똑같이 하면 돼요. 맥은 응용 프로그램 폴더의 앱을 새 것으로 **바꾸기**.
- 앱 자료 형식이 바뀌는 버전이면 처음 열 때 자동으로 바꾸고, 바꾸기 전에 자동 백업해요. 첫 실행 안내는 다시 나오지 않아요.

### 안드로이드 서명 키 (개발자·판매자용, 한 번만)
안드로이드는 모든 버전이 **같은 서명 키**로 만들어져야 덮어쓰기 설치가 돼요. 키 파일은 저장소에 넣지 않고 GitHub 비밀 값으로 넣어요.
1. 컴퓨터에서 키 만들기 (Java 가 있으면): `keytool -genkey -v -keystore release.jks -keyalg RSA -keysize 2048 -validity 10000 -alias channelbiseo`
2. `base64 -w0 release.jks` 결과를 복사
3. 저장소 **Settings → Secrets and variables → Actions → New repository secret** 에 4개 추가:
   `ANDROID_KEYSTORE_BASE64`(2번 결과), `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`(`channelbiseo`), `ANDROID_KEY_PASSWORD`
4. `release.jks` 와 비밀번호는 잃어버리지 않게 따로 보관 (잃어버리면 다음 버전을 덮어쓸 수 없어요)

키를 넣기 전에 받은 안드로이드 앱(1.1.0 이하)은 서명이 달라서 **한 번만** 지우고 새로 설치해야 해요. 지우기 전에 설정 → **백업 만들기** 에서 "다운로드" 같은 공용 폴더를 골라 백업하고, 새로 설치한 뒤 **백업에서 되살리기** 로 가져오세요. 연결 열쇠는 다시 넣어야 해요.

| 제작 | 쇼츠·롱폼·다큐·사진 게시물·음성 대화형 만들기, 영상 넣기, 썸네일, 비공개 업로드, 확인 대기 목록 |
| 블로그 | 구글 블로그 연결·글 다듬기·새 글(초안), 티스토리 글 만들기(복사해서 올리기) |

그 밖의 편리한 기능: 채널별 **설명 템플릿**(채널 상세), 한 화면에서 보는 **일괄 수정 미리보기**, 조회수가 빨리 느는 **주목할 영상**(홈), **검색어 추천**·**썸네일 2개 비교**(제작 상세), **게시 달력**(제작).

어느 화면에서든 오른쪽 아래 **마이크 버튼**을 누르고 말하면 돼요. 예:
- "이번 주 조회수 보여줘"
- "요리 채널에 쇼츠 하나 만들어"
- "비공개 영상 목록 읽어줘"
- "오늘 수정 내역 알려줘"
- "메모, 다음 주에 강릉 커피 영상 찍기"
- "아침 브리핑 해줘"

음성 인식이 안 되는 기기에서는 같은 창에 글자로 입력하면 돼요.

## 4. 구글 연결 준비하기 (유튜브·구글 블로그 실제 연결)

실제 채널을 연결하려면 **구글 클라우드에서 "클라이언트 ID" 를 한 번 만들어** 앱에 넣어야 해요. 한 번만 하면 됩니다.

> **가장 쉬운 방법:** 앱의 **설정 → 계정 연결 → "구글 연결 준비 마법사"** 를 누르세요. 7단계마다 눌러야 할 구글 화면을 바로 열어 주고, 마지막에 받은 JSON 파일을 **"JSON 파일 불러오기"** 로 고르면 번호와 비밀 값이 자동으로 채워져요.

마법사와 같은 순서 (2026년 구글 화면 기준, 메뉴 이름은 **Google Auth Platform**):
1. https://console.cloud.google.com/projectcreate 에서 새 프로젝트 만들기 (이름 예: 채널비서).
2. **API 켜기**: "YouTube Data API v3" 와 "Blogger API v3" 를 각각 열어 **사용**.
3. **Google Auth Platform → 브랜딩**: 앱 이름·내 이메일 입력 → 저장. **대상(Audience)**: 사용자 유형 **외부**.
4. **클라이언트 → 클라이언트 만들기**: 애플리케이션 유형 **데스크톱 앱** → 만들기 → **JSON 다운로드**.
   (웹 애플리케이션으로 만들면 앱이 "유형이 달라요, 데스크톱 앱으로 다시 만들어 주세요" 라고 알려 줘요.)
5. **대상(Audience) → 테스트 사용자**: 유튜브 채널이 있는 내 구글 계정을 추가 ← 중요
6. 앱 **설정 → 계정 연결 → JSON 파일 불러오기** 로 4번 파일을 고르기 (또는 두 값을 붙여 넣고 저장).
7. **채널 → 채널 등록 → 구글로 연결** 을 누르면 구글 로그인 창이 열려요. 로그인하고 권한을 허락하면 끝.

📷 `docs/사진/04-google-client.png` — 데스크톱 앱 클라이언트 만들기 화면

알아 두실 점:
- 앱이 아직 구글 심사를 받지 않은 "테스트" 상태라서 **4단계에 등록한 테스트 사용자만** 연결할 수 있고, 연결은 **7일마다 만료**돼요. 만료 이틀 전부터 아침 브리핑에서 알려 드리니 "다시 연결" 만 누르면 돼요. (구글 심사를 통과하면 만료가 없어져요 — `docs/배포준비.md`)
- 로그인 창에 "확인되지 않은 앱" 이 보이면 **고급 → (앱 이름)(으)로 이동** 을 누르면 됩니다. 내가 만든 앱이라 안전해요. (마법사 7단계에 그림으로 있어요)
- 이 구글 계정에 유튜브 채널이 없으면 앱이 "이 구글 계정에는 아직 채널이 없어요" 라고 알려 주고 **다른 계정으로 연결** 을 고를 수 있어요.
- 브랜드 계정 채널은 로그인 창에서 채널을 고르는 방식이라, 채널마다 한 번씩 "채널 등록" 을 해야 할 수 있어요.
- 휴대폰에서는 자료를 보고 확인하는 용도예요. 컴퓨터의 자료를 휴대폰으로 옮기려면 컴퓨터에서 **설정 → 백업 만들기** → 파일을 휴대폰으로 옮김 → 휴대폰에서 **백업에서 복원**.

### 앱 꾸미기
**설정 → 보기와 듣기 → 앱 꾸미기** 에서 앱 이름, 아이콘(마스코트 5가지 색 또는 내 그림), 색 묶음(기본·바다·숲·노을)을 바꿀 수 있어요.
- 안드로이드: 기본 아이콘 5가지는 홈 화면 아이콘도 바로 바뀌어요. 내 그림·내 이름은 **"홈 화면에 바로가기 만들기"** 로.
  1.2.0 으로 처음 업데이트하면 홈 화면 아이콘을 한 번 다시 놓아야 할 수 있어요 (앱 목록에서 끌어다 놓기).
- 윈도우·맥: 앱 안에 바로 적용되고, **"아이콘 파일 저장"** 을 누르면 바탕화면 바로가기 아이콘을 바꾸는 법을 알려 드려요.

## 5. 유튜브 하루 사용량(한도)

유튜브는 하루에 쓸 수 있는 양이 정해져 있어요 (기본 10,000).

| 작업 | 사용량 |
|---|---|
| 목록 읽기 | 1 |
| 제목·설명·키워드 수정 | 50 |
| 썸네일 올리기 | 50 |
| 영상 업로드 | 약 1,600 |

- 현황 화면에 오늘 남은 양이 보여요. 모자라면 앱이 그 작업을 멈추고 **다음 날** 이어서 해요. 업로드는 자동으로 하지 않고 "내일 올리기 준비됨" 으로 두니, 다음 날 버튼만 누르면 돼요.
- 하루 기준은 미국 태평양 시간 자정이에요 (한국 시간 오후 4~5시).
- **한도 늘리기**: 구글 클라우드 콘솔 → **API 및 서비스 → YouTube Data API v3 → 할당량** → "할당량 증가 요청" (또는 https://support.google.com/youtube/contact/yt_api_form ) 에서 채널 목록과 사용 목적을 적어 신청. 심사에 몇 주 걸릴 수 있어요. 늘어나면 앱 **설정 → 유튜브 하루 사용량 한도** 숫자를 바꿔 주세요.

## 6. AI 연결 (Claude)

1. https://console.anthropic.com 에서 API 키를 만듭니다.
2. 앱 **설정 → AI 연결** 에 붙여 넣고 저장. 키는 기기의 보안 저장소에만 저장돼요.
3. **한 달 비용 한도** 를 정하세요 (기본 10달러). 한도에 닿으면 자동 작업이 멈추고 연습 모드로 바뀌어요.
4. AI 를 쓰는 작업 전에는 예상 비용을 보여 주고 물어봐요.

모델은 기본 Claude Opus 5.5 이고, 비용을 줄이려면 Sonnet 5.5 / Haiku 5.5 로 바꿀 수 있어요.

## 7. 자동 작업 (컴퓨터에서만)

**설정 → 자동 작업 실행기** 를 켜고 시간대(예: 새벽 2시~6시)를 정하면, 하루 한 번 채널·블로그를 새로 불러오고 제목·설명·키워드를 다듬어요.
- 기본은 **꺼짐**이에요. 시작할 때와 끝날 때 알림이 와요.
- 처음 한 달은 채널당 하루 3개까지만 고쳐요 (기본 2개).
- 업로드·삭제·공개는 자동으로 절대 하지 않아요.
- 모든 수정은 **되돌리기** 버튼 하나로 원래대로 돌아가요. 현황 → "오늘 수정 내역 보기" 에서 하나씩 또는 하루치를 한 번에 되돌릴 수 있어요.
- 앱이 켜져 있어야 정한 시간에 실행돼요 (창을 내려 두는 것은 괜찮아요).

## 8. 제작 도구 연결

**설정 → 콘텐츠 제작 → 제작 도구 연결**
- 힉스필드: API 키 입력. 영상을 만들 때마다 예상 크레딧과 남은 크레딧을 보여 주고, 승인해야만 만들어요.
- 피그마: 피그마 개발자 설정에서 앱을 만들고, 돌아오는 주소로 `http://127.0.0.1:53682/callback` 을 등록한 뒤 클라이언트 ID·보안 비밀을 넣고 연결.
- 구글 비즈·브루: 공식 연결 방법이 없어 준비 중이에요. 대신 직접 만든 영상 파일을 넣을 수 있어요.

## 9. 문제가 생기면

- 화면에 나오는 안내의 **다시 시도 / 다시 연결 / 내일 다시 시도** 버튼을 눌러 주세요.

- **백업 만들기 / 백업에서 복원** 으로 자료를 보관하고 되살릴 수 있어요. (보안을 위해 계정 연결 정보는 백업에 들어가지 않아 복원 후 "다시 연결" 이 필요해요)
- **초기화** 는 두 번 확인한 뒤 이 사용자의 자료를 모두 지워요. 유튜브의 영상은 그대로예요.
