# 바뀐 내용

## 1.1.0
**업데이트**
- 설정 맨 위 "업데이트 확인": 새 버전이 있으면 알려 주고, "업데이트"를 누르면 내 자료를 먼저 백업한 뒤 설치해요(자동으로 내려받지는 않아요). 하루 한 번 조용히 확인해 홈에 "새 버전 있어요"를 띄워요
- 새 버전을 설치해도 설정·대화·주제·별표·태그·메모·AI 열쇠가 그대로 남아요(이전 자료는 자동 변환, 변환 전 자동 백업). 이미 쓰던 분은 첫 안내를 건너뛰어요

**화면**
- 홈 맨 위에 큰 검색창, 그 아래 "오늘 할 일", 색깔 있는 주제 타일(2열), 최근 대화, 큰 숫자 통계
- 아래(휴대폰)·왼쪽(컴퓨터) 메뉴로 홈·찾기·주제·날짜·설정 이동. 탭을 옮겨도 보던 위치가 남아요
- 넓은 화면에서는 목록과 대화 내용을 나란히(주제는 주제·목록·내용 3칸)
- 주제마다 다른 색, 대화 카드 왼쪽 색 띠, AI 배지(클로드 주황·챗GPT 초록·제미나이 파랑), 찾은 낱말 형광펜, 찾은 개수를 큰 숫자로
- 테두리만 있던 상자를 색이 채워진 카드로, 어두운 화면에서도 카드가 한 단계 밝게
- 설정을 묶음별 카드로 정리하고, 지우기 같은 위험한 기능은 맨 아래 빨강 카드로

**편의·오류 대비**
- 홈과 설정에 "가져온 대화 수 / AI 연결 / 지메일 연결" 상태를 따로 표시(바꾸면 바로 반영)
- 샘플 대화는 실제 대화를 넣으면 자동으로 숨고, 설정에서 다시 볼 수 있어요
- 실패 창마다 "다시 시도"와 "문제 신고". 창을 닫은 뒤 다시 시도해도 앱이 멈추지 않아요
- 목록을 내려 보는 중에 자료가 바뀌어도 맨 위로 튀지 않아요
- 만료된 다운로드 링크, 빈 파일, 대화가 없는 파일을 구분해서 안내하고 다음에 할 일을 보여줘요
- 읽을 수 없는 파일은 "어느 AI 파일인지 골라 주세요" 버튼으로 바로 다시 읽기
- AI 열쇠·구글 JSON은 "파일 불러오기"로 넣을 수 있어요

**새 기능**
- 지메일 연결(읽기 전용): 단계별 준비 도우미, JSON 불러오기, 내보내기 안내 메일이 오면 "내려받을 때가 됐어요"
- 앱 꾸미기: 표시 이름(창 제목에도), 아이콘(안드로이드는 홈 화면 아이콘·이름까지), 색 테마 5가지
- 대화 화면에 "원본으로 가기"와 마크다운·PDF·텍스트 내보내기 버튼
- 한국어 계정 제미나이 테이크아웃(한국어 폴더 이름, HTML·JSON 함께) 대응, 깨진 메시지가 있어도 대화는 가져오기
