# 개발 계획 — AI 대화 기록 정리 비서

이 계획은 작업 지시서(2번)를 기준으로 하며 승인 없이 바로 진행합니다.

## 기술
- Flutter 3.47 (안드로이드·윈도우·맥, 리눅스는 개발 확인용, 아이폰은 구조만)
- 저장: 기기 내 SQLite(FTS5 전문 검색) + 대화 본문 AES-256-GCM 암호화
- 분류·요약: 기본은 "검색만" 모드(키워드 분류, 비용 없음). 키를 넣으면 Claude API(제공자 교체 가능 구조)
- 세 플랫폼 빌드: GitHub Actions

## 단계
### 0. 뼈대
- 앱 실행, 테마 파일(색·크기·간격·그림자·움직임), 글씨 크기 3단계, 첫 실행 마법사
- 로컬 사용자(여러 명), 설정, 오류 처리·기기 내 로그·문제 신고
- 파일 넣기(선택·끌어다 놓기·안드로이드 공유), 음성 틀(지원 안 되면 글자 입력)
### 1단계 — 통합 목록과 검색
- 파서 3종(Claude·ChatGPT·제미나이) + 샘플 파일 3종 + 파서 테스트
- 중복 없이 가져오기, 백그라운드·진행률·취소
- 통합 목록(나눠 불러오기), 본문 검색(정확 일치 / 비슷한 말), 음성 검색, 미리보기, 읽어주기, 원래 대화 링크
- 별표, 태그, 대화 내보내기(Markdown·텍스트·PDF), 음성 메모
### 2단계 — 주제 분류와 타임라인
- 키워드 분류(검색만 모드) / AI 분류, 사용자가 고친 내용 기억
- 주제 이름 바꾸기·옮기기·합치기·나누기·하위 주제, 여러 주제 표시
- 날짜별 타임라인(연·월 이동, 주제 필터), 음성 명령
### 3단계 — 요약과 결정 모음
- 대화별 한두 줄 요약, 주제별 "지금까지 정한 내용", 읽어주기
- "이 주제와 관련된 지난 대화" 추천
- 백업·복원, 초기화, 내보내기 알림, 지메일 연결 틀

## 검증
- 단위·파서·흐름 테스트, 린트, 리눅스 빌드
