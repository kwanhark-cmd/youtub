# 막힌 것 (BLOCKERS)

1. **안드로이드 SDK 설치 불가 (이 환경)** — `dl.google.com` 접속이 네트워크 정책으로 거부(403). 안드로이드 APK는 GitHub Actions(`.github/workflows/build.yml`)에서 만듭니다.
2. **윈도우·맥 빌드** — 리눅스 환경이라 직접 빌드 불가. GitHub Actions에서 만듭니다.
3. **카메라·마이크 없음** — 촬영은 "사진 파일 넣기", 음성은 "글자 입력"으로 대체해 테스트했습니다.
4. ~~지메일 자동 읽기~~ — 1.1.0에서 해결: 설정 → 지메일 카드의 단계별 도우미로 사용자가 직접 구글 클라이언트를 만들어 연결.
5. **리눅스 음성** — `speech_to_text`·`flutter_tts`가 리눅스를 지원하지 않아 리눅스에서는 글자 입력칸으로 대체(앱은 멈추지 않음).

## 1.1.0 작업 중
6. **안드로이드 서명 열쇠를 GitHub Secrets에 넣는 일** — 이 환경에서는 저장소 비밀 값(Secrets)을 직접 넣을 수 없습니다. 고정 열쇠는 만들어 두었고(사용자에게 파일로 전달), 사용자가 저장소 Settings → Secrets and variables → Actions 에 `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD` 두 값을 한 번 넣어야 합니다. 넣기 전에는 임시 열쇠로 서명되어 덮어쓰기 업데이트가 안 됩니다(빌드는 됨, 경고 표시).
7. **1.0.0 안드로이드 → 1.1.0** — 1.0.0은 매번 다른 임시 열쇠로 서명되어 덮어쓰기가 불가능합니다. 한 번만 "백업 → 삭제 → 설치 → 되살리기"가 필요합니다(README 안내).
8. **실제 구글 계정으로 지메일 연결 시험** — 이 환경에는 구글 계정이 없어 가짜 구글 서버로 전체 흐름(로그인 → 돌아오기 → 열쇠 → 메일 읽기 → 만료)을 시험했습니다. 실제 연결은 사용자 계정에서 처음 확인됩니다.
9. **맥 자기 업데이트·윈도우 설치 파일 실제 실행** — 이 환경은 리눅스라 빌드(Actions 통과)까지만 확인. 리눅스 자기 업데이트 스크립트와 동일한 방식.
10. **리눅스 키링 없는 환경** — 보안 저장소를 못 쓰면 앱 자료에 보관하고 설정에 그 사실을 표시합니다(백업·기록에는 넣지 않음).
