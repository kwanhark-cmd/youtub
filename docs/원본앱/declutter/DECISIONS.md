# 결정 기록 (DECISIONS)

지시서에 없거나 환경 때문에 바꾼 결정을 기록합니다.

1. **Flutter 사용 (지시서대로).** Flutter 3.47.9 / Dart 3.13.7 설치 성공. Electron 대체는 필요 없었음.
2. **안드로이드 빌드는 GitHub Actions에서만.** 이 환경은 안드로이드 SDK 서버(dl.google.com)가 차단됨 → BLOCKERS.md 참고.
3. **AI 모델:** Claude `claude-opus-5-5` (입력 $4 / 출력 $20, 100만 토큰당). Dart용 공식 SDK가 없어 HTTP로 직접 호출. 비용을 줄이려고 사진은 긴 변 1568px 이하로 줄여 보내고, 노력(effort) 단계는 `low`. 거절(refusal) 시 서버 쪽 대체 모델(`fallbacks: "default"`) 사용.
4. **사진 한 장당 예상 비용:** (가로×세로÷750) 토큰 + 질문·답변 토큰으로 계산. 1568×1176 사진 기준 약 2,500 토큰 → 약 $0.02(약 30원). 환율은 설정에서 바꿀 수 있게 기본 1,400원.
5. **저장:** SQLite. 안드로이드·맥은 `sqflite`, 윈도우·리눅스는 `sqflite_common_ffi`. 테스트는 메모리 DB.
6. **상태 관리:** `provider` (가장 흔하고 단순).
7. **Lottie 미사용.** 라이선스가 확실한 Lottie 파일을 확보하지 못해, 모든 움직임을 Flutter 기본 애니메이션 코드로 만듦("움직임 줄이기" 설정 시 0초).
8. **3D 아이콘:** Microsoft Fluent Emoji 3D(MIT) 26개, 256px PNG, 합계 약 0.9MB. 라이선스 `assets/licenses/`.
9. **마스코트:** 직접 그린 SVG 5종(인사·생각 중·추천·주의·축하) `assets/mascot/` 한 폴더. 파일만 바꾸면 교체됨.
10. **한국어 글꼴:** Noto Sans KR(OFL)을 보통·굵게 두 가지로, 한글 완성형 11,172자 + 영문·기호만 남겨 각 2.9MB로 줄임.
11. **영상 장면 뽑기:** `fc_native_video_thumbnail`로 2초 간격(최대 20장). 지원 안 되는 플랫폼이면 "사진 여러 장 고르기"로 안내.
12. **음성:** `speech_to_text`(안드로이드·윈도우·맥), `flutter_tts`. 리눅스나 실패 시 마이크 대신 글자 입력칸.
13. **지메일 자동 읽기:** 구글 로그인 연동(OAuth)은 앱 등록·심사가 필요해 이번에는 "준비 중" 표시만. 기본 방식인 공유하기·붙여넣기는 구현.
14. **알림:** `flutter_local_notifications`로 매일 아침(기본 8시). 절전으로 놓쳐도 앱을 열면 "밀린 알림" 목록에 보임(앱 안 알림 기록 테이블).
15. **1년 경과 폐기 이동:** 판매 등록일 기준. 358일째 "7일 뒤 폐기로 옮겨요" 미리 알림, 365일째 이동 + 알림 + 되돌리기. 기기 시간이 뒤로 가도 경과일은 0 미만이 되지 않고, 앱이 본 가장 늦은 시간을 기억해 시간이 앞뒤로 바뀌어도 꼬이지 않음.
16. **가격 인하 추천:** 판매 시작 후 14일마다 안 팔리면 10% 인하 추천(1,000원 단위 반올림, 시세 최저값 아래로는 추천 안 함). 사용자가 확정해야 바뀜.
17. **백업:** zip(DB 내용 JSON + 사진) → 비밀번호로 AES-GCM 암호화(PBKDF2). 확장자 `.binugi`.
18. **타임랩스:** 같은 자리 사진들을 이어 움직이는 GIF로 만들고 마지막에 엔딩 크레딧 화면 추가. (기기 안에서 MP4 인코딩은 추가 프로그램이 필요해 GIF로 결정.)
19. **내보내기 폴더:** 앱 문서 폴더 아래 `내보내기/1번앱_사연`, `내보내기/1번앱_타임랩스`, `내보내기/3번앱_디지털기록`.
20. **대형폐기물 비용:** 지역마다 달라 대표적인 범위만 안내하고 "구청에 꼭 확인" 문구를 함께 표시.

## 1.1.0 (업데이트 방식)
21. **자료 위치는 그대로**: 1.0.0부터 자료는 앱 파일과 분리된 사용자 폴더(맥 Application Support, 윈도우 %APPDATA%, 안드로이드 앱 자료, 리눅스 ~/.local/share)에 있었음. 옮길 필요 없음.
22. **AI 열쇠·구글 비밀번호는 OS 보안 저장소**(flutter_secure_storage). 예전 DB에 있던 열쇠는 첫 실행 때 1회 옮기고 DB에서 지움. 보안 저장소를 못 쓰는 기기(키링 없는 리눅스 등)는 앱 자료에 보관하고 백업에서는 뺌.
23. **맥 샌드박스 끄기**: 앱이 스스로 새 버전으로 바뀌려면 샌드박스 밖이어야 함. 그 결과 자료 폴더가 ~/Library/Containers/... → ~/Library/Application Support/... 로 바뀌므로 1회 자동 이전(`data_location.dart`).
24. **자료 변환 전 자동 백업**: DB 버전이 낮으면 변환 전에 사진 포함 자동 백업(기기 안, 최근 3개). 업데이트 설치 직전에도 자동 백업.
25. **업데이트 설치 방식**: 안드로이드 = APK 설치 화면, 윈도우 = Inno Setup 설치 파일(사용자 폴더 설치, 관리자 권한 불필요, 고정 AppId), 맥·리눅스 = 앱이 닫힌 뒤 작은 스크립트가 새 앱으로 바꾸고 다시 실행.
26. **Releases 올리는 조건**: main 커밋 메시지에 "[배포]"가 있거나 직접 실행했을 때만 (작업 중간 병합이 미완성 버전으로 배포되지 않게). 같은 버전 태그가 있으면 다시 올리지 않음.
27. **안드로이드 서명 열쇠**: 새로 만든 고정 열쇠(RSA 2048, 100년)를 Secrets로. 저장소에는 올리지 않음.

## 1.1.0 (오류 대비·화면·전용 수정)
28. **대화상자는 항상 살아 있는 화면에서**: 전역 navigatorKey·알림줄(messengerKey)을 두고, 모든 대화상자 도우미가 넘겨받은 화면이 사라졌으면 앱 최상위 화면을 씀. 알림줄 메시지는 화면 없이도 표시.
29. **실패 창 하나로 통일**(`showFailure`): 다시 시도 / 다른 방법 / 문제 신고 / 닫기. 띄울 때 `[단계] 원인`을 오류 기록에 남김.
30. **window_manager는 0.5.1 사용**: 0.6.0은 새 네이티브 층으로 바뀐 직후라 위험해 성숙한 0.5.x를 고정.
31. **안드로이드 아이콘 바꾸기 = activity-alias 4개**(상자·집·재활용·반짝). 런처 이름은 고정("비우기 비서")이고 앱 안 이름·창 제목·알림 제목만 바뀜(안드로이드는 런처 이름을 실행 중 바꿀 수 없음). 사용자 사진 아이콘은 앱 안에서만.
32. **화면 재설계 규칙**: 당근마켓(사진 큰 카드·큰 가격·상태 배지), Duolingo(하루 한 개 큰 카드·채도 높은 타일·축하), Tinder(카드 하나 크게 밀기), 토스(큰 숫자+작은 설명). 촬영 버튼은 내용을 가리지 않게 아래 고정 띠로.
33. **MP4 타임랩스는 순수 Dart로 직접 작성**: 기기 영상 인코더 플러그인(ffmpeg_kit 등)은 지원 종료·플랫폼별 차이가 커서, 화질 손실 없는 키 프레임(I_PCM)+같은 화면 유지 프레임(P_Skip)으로 표준 H.264 MP4를 만듦. 30fps, 세로 720×1280 / 가로 1280×720. 사진 5장 약 1.4초·6.8MB. ffmpeg로 해독 검증.
34. **지메일은 "데스크톱 앱" OAuth + 이 기기(127.0.0.1)로 돌아오는 방식 + PKCE**, 권한은 읽기 전용(gmail.readonly). 구글 비밀번호·갱신 열쇠는 보안 저장소. 테스트 모드 7일 만료를 따로 알아보고 안내.
35. **사진 정리**: 판매 완료·폐기 완료이고 사연·디지털 기록이 없는 물건만, 큰 사진·원본을 지우고 작은 사진(썸네일)은 남김.
36. **마켓 열기**: https 주소를 "브라우저가 아닌 앱"으로 먼저 열고(설치돼 있으면 앱), 안 되면 브라우저로. 글을 대신 올리지 않음.
