# 작업 계획 (PLAN)

앱 이름: **집안 물건 비우기 판매 폐기 비서** (코드 이름 `binugi`)

## 원칙
- 분류는 딱 세 가지: 지금 쓰는 것(파랑) / 판매(초록) / 폐기(빨강). 보관·보류 없음.
- AI 키가 없으면 "연습 모드"(가짜 결과)로 모든 흐름이 동작.
- 당근마켓·번개장터 자동 게시·채팅 읽기 코드는 만들지 않음. 판매글은 "복사"만.
- 개발·테스트 중 비용이 드는 외부 API 호출 금지(테스트는 가짜 HTTP 사용).

## 구조
```
lib/
  main.dart            시작, 전역 오류 처리
  app.dart             테마·글씨 크기·첫 실행 마법사 분기
  theme/app_theme.dart 색·크기·간격·둥글기·그림자·애니메이션 시간 (한 파일)
  core/                시계(가짜 시계 주입), 로그(키·사진 기록 금지), 오류 종류, 돈 표시
  data/                SQLite(버전·자동 변환), 모델, 저장소(사용자별 분리)
  services/            AI(연습/Claude), 사진 줄이기, 영상 장면 뽑기, 음성, 알림,
                       판매(가격 인하·1년 이동), 폐기 안내, 제미나이 가져오기,
                       백업·복원(암호화), 내보내기 폴더, 타임랩스, 오늘 할 일
  state/app_state.dart 화면 상태
  ui/                  화면, 공용 위젯(3D 타일, 큰 버튼, 마스코트)
```

## 단계
| 단계 | 내용 |
|---|---|
| 0 뼈대 | 앱 실행, 테마, 설정, 첫 실행 마법사, 물건 목록, 음성 틀(글자 입력 대체) |
| 1단계 | 사진·영상 등록, AI 인식(연습 모드), 수정·추가 화면, 제미나이 붙여넣기 가져오기, 분류 추천(스와이프+버튼+음성), 결정 도움 질문 |
| 2단계 | 판매 도우미: 판매글 작성·복사, 시세 범위, 가격 인하 알림, 판매 상태, 택배 안내, 1년 경과 폐기 이동 |
| 3단계 | 폐기 도우미(분리수거·대형폐기물·나눔·기부·디지털 기록), 진행 현황(음성), 타임랩스, 백업·복원, 문제 신고 |
| 검증 | 단위·흐름·디자인(큰 글씨·360×640·어두운·고대비) 테스트, 대비 검사, 안전 체크리스트, 누락 점검 |

각 단계: 구현 → 자체 검증(analyze, test, linux 빌드) → 오류 수정 → 커밋 → docs/보고/N단계.md
