# 누락 점검 (1.1.0 수정 지시서를 처음 보는 사람처럼 다시 읽고 확인)

1.0.0 점검표는 아래 "1.0.0 점검"에 그대로 두었습니다.

## 1. 업데이트 방식
| 지시서 항목 | 상태 | 위치·확인 방법 |
|---|---|---|
| 자료가 앱 파일 밖 사용자 폴더·OS 보안 저장소에 있는지 확인, 아니면 1회 이전 | ✅ | 자료는 원래 사용자 폴더. AI 열쇠는 DB → 보안 저장소 1회 이전(`settings.dart`), 맥은 샌드박스 폴더 → Application Support 1회 이전(`data_location.dart`) |
| 앱 식별자(패키지 이름·번들 ID·앱 이름) 변경 금지 | ✅ | `com.binugi.binugi` 그대로, 윈도우 설치 AppId 고정 |
| 안드로이드 같은 서명 키, Secrets 고정 | ⚠️ 사용자 1회 작업 | 열쇠 생성·전달 완료, Secrets 등록은 사용자만 가능 (BLOCKERS 6) |
| 자료 자동 변환 + 변환 전 자동 백업(사진 포함) | ✅ | DB v2→v3, `createSafetyBackup` |
| 현재 버전으로 만든 실제 자료로 업그레이드 테스트 | ✅ | 1.0.0 코드로 만든 자료(물건 41개·사진) `test/fixtures`, `upgrade_test.dart` + 실제 리눅스 앱 실행 확인 |
| 이미 설정이 있으면 첫 실행 마법사 건너뛰기 | ✅ | `startup()` |
| 설정 맨 위 "업데이트 확인" → 알림 → 눌러서 설치, 설치 전 자동 백업, 자동 다운로드 안 함 | ✅ | `update_card.dart`, `update_service.dart` |
| 안드로이드 APK 설치 화면 / 맥 새 앱으로 교체 / 윈도우 설치 파일 실행 | ✅ | `install()` |
| 앱 시작 시 하루 한 번 조용히 확인, 홈 "새 버전 있어요" 배지 | ✅ | `quietUpdateCheck`, 홈 앱바 |
| Actions가 Releases에 올림(버전 태그, 한국어 변경 내역), 버전 올림·설정에 표시 | ✅ | `build.yml` release 작업, `CHANGELOG.md`, 1.1.0 |
| README "새 버전 설치 = 덮어쓰기, 자료 유지" | ✅ | README "새 버전 설치" |
| 자동 테스트: 물건·사진·사연·판매 상태·설정·열쇠 유지 | ✅ | `upgrade_test.dart` |

| 물건 0개·권한 거부·기기 없음·AI 한도 초과 → 안내 + 다음 행동(자동 대체) | ✅ | 빈 화면 버튼, 카메라 → 파일 고르기, 마이크 → 글자 입력, 한도 → 직접 이름 적기 |
| 표시 이름(홈·창 제목·알림 즉시) | ✅ | `appName`, window_manager, 알림 제목 |
| 아이콘 선택(기본 여러 개·사용자 사진), 색 테마 | ✅ | 설정 → 앱 꾸미기, `colorThemes` |
| 안드로이드 activity-alias 런처 아이콘 / 맥·윈도우 바로가기 그림 안내 | ✅ | `MainActivity.kt`, 그림 안내 창 + 아이콘 파일(png·ico) |

## 3. 화면 재설계
| 항목 | 상태 | 위치·확인 |
|---|---|---|
| 오늘 할 일이 주인공(사진 화면 폭 전체 + 큰 색 버튼 3개), 그 아래 현황 숫자 띠 | ✅ | `TodayHero`, `StatStrip`, 테스트 "오늘 할 일이 맨 위에 가장 크게" |
| 크기로 중요도: 오늘 할 일 > 촬영 버튼 > 분류 타일 3개 > 현황 띠, 같은 크기 3개 이상 나란히 금지(분류 타일 예외, 색 다름) | ✅ | 홈 구성 |
| 테두리만 있는 상자 금지: 채운 카드 + 부드러운 그림자, 어두운 모드 한 단계 밝은 카드 | ✅ | `Panel`, `ItemCard`, 어두운 카드 #262A30 |
| 분류색·상태색 고정, 물건 카드 사진 대부분 + 왼쪽 색 띠 + 상태 배지 | ✅ | `ItemCard` |
| 카드 형식: 물건=사진형, 현황=숫자형, 판매글=복사 행동형, 폐기=단계 목록형 | ✅ | |
| 글자 위계 4단계, 카드 간격 1.5배, 설정 그룹별 카드, 위험 동작 맨 아래 빨강 | ✅ | `AppText`, `cardGap`, 설정 화면 |
| 성능: 입체 효과는 타일·주요 버튼만, 썸네일 캐시, 시작·전환 속도 측정 | ✅ | 리눅스 실제 첫 화면 340ms(물건 41개 자료 790ms), 테스트 측정 |
| 전후 스크린샷, 큰 글씨·작은 화면·어두운·고대비 테스트 | ✅ | `docs/화면/비교/`, `design_test.dart` |
