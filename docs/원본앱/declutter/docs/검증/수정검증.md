## 새 테스트
- **업그레이드**: 1.0.0 코드가 만든 실제 자료(물건 41개·사진·사연·판매 상태·설정·AI 열쇠) → 새 버전으로 열기 → 모두 남음, 열쇠는 보안 저장소로, 변환 전 자동 백업(사진 41장 포함), 마법사 건너뜀, 두 번째 업데이트도 그대로
- **맥 예전 자료 폴더 1회 이전**, 자동 백업에서 되살리기, 업데이트 확인·내려받기(가짜 서버), 버전 비교, 기기별 설치 파일 고르기, pubspec 버전 = 앱 표시 버전
- **스크롤 유지**: 목록을 1500px 내린 뒤 물건 추가·갱신 → 위치 유지
- **실패 → 다시 시도**: 다시 시도하는 동안 원래 화면이 닫혀도 앱이 죽지 않고 다음 창이 뜸, 모든 오류 창에 "문제 신고"
- **카메라 권한 거부** → 오류 대신 안내 후 사진 파일 고르기로 자동 대체
- **연결 상태 즉시 반영**, 연습 물건 자동 숨김
- **화면**: 오늘 할 일이 맨 위·화면 폭 전체·다른 카드보다 2배 이상 큼, 분류 타일 3개 색이 서로 다름, 성능 측정
- **MP4**: H.264·30fps·프레임 수·색이 맞는지 ffprobe/ffmpeg로 해독 확인, 세로·가로 크기
- **지메일**: JSON 읽기, 브라우저 로그인 → 이 기기로 돌아오기 → 열쇠 받기(PKCE·읽기 전용 권한), 제목 규칙으로 메일 읽기, 7일 만료 구분
- **사진 정리**: 완료 물건 큰 사진만 정리, 사연 있는 물건 유지
