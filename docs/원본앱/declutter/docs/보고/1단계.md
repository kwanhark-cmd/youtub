# 1단계 보고 — 물건 등록·분류 추천

**완성**
- 사진 등록(카메라/앨범/파일 여러 장), 저장 시 긴 변 1568px로 줄이고 썸네일 300px(원본은 설정 시만)
- 방 전체 영상 → 2초 간격 장면(최대 20장) 뽑기 → 장면마다 AI 인식, 진행률·취소
- AI 결과 확인 화면: 이름·상태 고치기, 체크로 빼기, "놓친 물건 추가", 인식 실패 시 "직접 이름을 적어주세요" 입력칸
- 연습 모드(키 없음, 비용 0원)·Claude 연결 둘 다 지원, 사진 전송은 사용자가 켰을 때만
- AI 실패 구분 안내: 키 없음/키 틀림/인식 실패/시간 초과/월 한도 초과/인터넷/거절/서버
- 제미나이 정리 글: 안드로이드 공유하기 받기 + 붙여넣기 + 목록 파일(txt·csv) → 확인 후 등록
- 분류: 홈 "오늘 할 일" 카드, 정리하기 스와이프(←폐기·판매→·↑지금 쓰는 것) + 버튼 + 음성("이건 판매"), 판매·폐기 음성 명령은 실행 전 확인
- 결정 도우미 질문 3개("최근 1년 안에 쓴 적 있나요?" 등)
- 분류 확정 시 카드가 분류색으로 물들며 날아가고 마스코트 축하, 되돌리기 버튼

**자체 검증**: 코드 검사 통과, 테스트 통과(파싱·음성 명령·AI 가짜 응답·한도·사진 줄이기·영상 장면), 리눅스 빌드 성공
