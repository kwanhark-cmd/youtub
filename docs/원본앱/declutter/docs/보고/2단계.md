# 2단계 보고 — 판매 도우미

**완성**
- 당근마켓·번개장터용 판매글(제목·설명·카테고리) 자동 작성, 전체/제목/설명 복사 버튼
- AI 시세 범위 표시 → 가격은 사용자가 직접 결정 (자동 수집 없음)
- 판매 상태 버튼: 판매중 / 예약 / 판매완료(판매 금액 입력 → 수입 합계)
- 가격 인하 추천: 14일마다 10%(설정에서 조절), 1,000원 단위, 시세 최저값 아래로는 추천 안 함, 알림은 주기마다 한 번
- 번개장터 택배 포장·발송 안내
- 1년 경과: 358일째 "7일 뒤 옮겨요" 미리 알림 → 365일째 폐기 목록 이동 + 알림 + "판매로 되돌리기"
- 날짜는 판매 등록일 기준, 기기 시간이 뒤로 가도 꼬이지 않음(앱이 본 가장 늦은 시각 기억)
- **자동 게시·채팅 읽기 코드 없음** (복사만)

**자체 검증**: 가짜 시계로 14일·358일·365일·시간 되감기 테스트 통과
