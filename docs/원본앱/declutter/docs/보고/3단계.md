# 3단계 보고 — 폐기 도우미·진행 현황

**완성**
- 물건 종류별 분리수거 방법(10가지 종류 + 기타)
- 대형폐기물: 지역(시·군·구)을 넣은 신고 순서 + 예상 수수료 범위 + "꼭 구청에 확인" 문구
- 무료 나눔·기부할 곳 추천(당근 나눔, 기부 가게, 도서관 등)
- 디지털로 남기고 버리기: 사진+사연 → `내보내기/3번앱_디지털기록`
- 사연 녹음(말 → 글) → `내보내기/1번앱_사연` (사진.jpg, 사연.txt, info.json)
- 진행 현황: 큰 숫자·진행 막대, 판매 수입 합계, 팔 물건 예상 가치, 음성으로 듣기
- 타임랩스: 같은 자리 사진 모아 이어 보기 + 엔딩 크레딧, 움직이는 그림(GIF) → `내보내기/1번앱_타임랩스`
- 백업·복원(비밀번호 암호화, 사진 포함, AI 키 제외), 문제 신고 기록 내보내기, 2번 확인 초기화, 버전 표시
- 앱 안 알림 모음(절전으로 놓친 알림), 아침 알림 시 음성 안내

**자체 검증**: 전체 흐름 자동 테스트, 디자인 자동 테스트 64+개 통과, 리눅스 실제 실행 확인
