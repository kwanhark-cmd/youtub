# 수정 보고 — 1.1.0

## 한 줄 요약
이제 **새 버전을 덮어써 설치해도 물건·사진·사연·판매 상태·설정·AI 열쇠가 그대로 남고**, 앱 안 "업데이트 확인"으로 새 버전을 받을 수 있어요. 오류가 나도 앱이 멈추지 않게 고쳤고, 화면을 "오늘 할 일이 주인공"인 모양으로 새로 꾸몄어요.

## 바뀐 것
### 1. 업데이트 방식
- 자료(물건·사진·영상 장면·사연·판매 상태·타임랩스·설정)는 앱 파일과 분리된 사용자 폴더에 있어요. AI 열쇠와 구글 비밀번호는 기기 **보안 저장소**로 옮겼어요(1회 자동).
- 자료 형식이 바뀌는 업데이트는 **바꾸기 전에 사진까지 자동 백업**하고 자동 변환해요. 이미 쓰던 자료가 있으면 첫 실행 마법사는 건너뛰어요.
- 설정 맨 위 **"업데이트 확인"**: 새 버전과 바뀐 내용을 보여 주고, 누르면 자동 백업 → 내려받기(진행률·취소) → 설치. 하루 한 번 조용히 확인해 홈에 "새 버전 있어요".
  - 안드로이드: 설치 화면이 열림 / 윈도우: 설치 도우미 실행 / 맥·리눅스: 앱이 닫힌 뒤 새 앱으로 바뀌고 다시 열림
- GitHub **Releases**에 버전별로 올라가요 (설치 파일 + 한국어 바뀐 내용).
- 맥은 앱이 스스로 업데이트할 수 있게 "샌드박스"를 끄고, 예전 자료 폴더를 1회 자동으로 옮겨요.

### 2. 오류 대비
- 실패 창을 닫은 뒤 다시 시도할 때 **앱이 죽던 문제를 앱 전체에서 차단**(살아 있는 화면에서만 창을 띄움).
- 모든 실패 창: **다시 시도 / 다른 방법 / 문제 신고 / 닫기**, 실패 원인과 단계(카메라·파일·AI 인식·저장·지메일·업데이트)를 기록.
- 목록을 내려 보는 중에 사진 처리·AI 인식이 끝나도 **맨 위로 튀지 않아요**.
- 카메라·마이크가 없거나 허락이 안 되면 오류 대신 안내하고 **사진 파일 고르기·글자 입력으로 자동 대체**.
- 홈과 설정에 **AI 연결 / 사진 AI 전송 / 지메일** 상태를 따로 표시, 저장하면 바로 바뀜. 연습 물건은 실제 물건이 생기면 자동으로 숨김.
- AI 열쇠·구글 JSON·제미나이 정리 파일은 **"파일 불러오기"** 버튼으로.
- **앱 꾸미기**: 표시 이름(홈·창 제목·알림), 아이콘(상자·집·재활용·반짝·내 사진), 색 테마 4가지. 안드로이드는 휴대폰 홈 화면 아이콘까지 바뀌고, 맥·윈도우는 바로가기 아이콘 바꾸는 그림 안내 + 아이콘 파일.

### 3. 화면 재설계
- 홈 맨 위 **오늘 할 일**: 오늘 정할 물건 사진을 화면 폭 전체로, 그 아래 **파랑·초록·빨강 큰 버튼 3개**. 그다음 숫자 띠(비운 개수·판매 수입), 색이 채워진 분류 타일 3개, 작은 보조 링크.
- 촬영 버튼은 화면 아래 가운데 고정 띠에 (내용을 가리지 않음).
- 물건 카드는 **사진이 카드 대부분**, 왼쪽 분류색 띠, 사진 위 상태 배지(판매중·예약중·거래완료), 큰 가격.
- 테두리만 있는 상자를 없애고 **색이 채워진 카드 + 부드러운 그림자**. 어두운 모드 카드는 바탕보다 한 단계 밝게.
- 판매글은 "복사하기 → 앱 열기" 행동형 카드, 폐기·택배 안내는 번호 단계 목록.
- 설정은 그룹별 카드(보기·꾸미기·지역·AI·지메일·음성과 알림·판매 규칙·사용자·자료 관리·앱 정보), 위험한 "모두 지우기"는 맨 아래 빨간 카드.

### 4. 이 앱 전용
- 타임랩스를 **유튜브용 MP4**(세로 9:16 또는 가로 16:9, 엔딩 크레딧 포함)로도 저장 → 내보내기/1번앱_타임랩스.
- **지메일 연결**: 단계별 "구글 연결 준비하기" 도우미(콘솔 바로가기 포함) → JSON 불러오기 → 구글 연결하기 → 제목이 `[비우기 정리]`인 제미나이 정리 메일 가져오기(읽기만).
- 설정에 **앱 용량** 표시, **판매·폐기 끝난 물건 사진 정리**(사연 있는 물건은 유지, 2번 확인).
- 판매글 복사 뒤 **"당근마켓 열기 / 번개장터 열기"** (앱이 있으면 앱으로). 자동으로 올리지는 않아요.

## 업데이트(새 버전 설치) 방법
1. 앱 **설정 맨 위 "업데이트 확인"** → "내려받아 설치". (자동 백업 후 설치)
2. 또는 GitHub 저장소 **Releases**에서 내 기기 파일을 받아 **그냥 덮어 설치**.
3. 물건·사진·설정은 그대로 남아요.

> ⚠️ **안드로이드에서 1.0.0을 쓰던 경우 한 번만**: 1.0.0 APK는 임시 서명이라 덮어쓰기가 안 돼요.
> 1.0.0에서 설정 → 백업 파일 만들기 → 앱 삭제 → 1.1.0 설치 → 백업에서 되살리기. 이후로는 덮어쓰기로 계속 업데이트돼요.

## 사용자가 해야 할 일 (한 번)
- **안드로이드 서명 열쇠를 GitHub Secrets에 넣기** — 따로 보낸 `서명열쇠_넣는법.md` 대로 두 값(`ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`)을 넣고, GitHub → Actions → "빌드와 테스트" → Run workflow(main). 그러면 Releases의 1.1.0에 안드로이드 설치 파일이 추가돼요. 열쇠를 넣기 전에는 덮어쓰기가 안 되는 APK를 Releases에 올리지 않도록 해 두었어요.

## 못 한 것과 이유
| 항목 | 이유 | 대신 한 것 |
|---|---|---|
| GitHub Secrets에 서명 열쇠 넣기 | 이 환경에서 저장소 비밀 값을 넣을 수 없음 | 열쇠를 만들어 사용자에게 전달 + 단계 안내 |
| 실제 구글 계정으로 지메일 연결 시험 | 이 환경에 구글 계정 없음 | 가짜 구글 서버로 전체 흐름 자동 시험 |
| 맥·윈도우에서 설치·자기 업데이트 직접 실행 | 이 환경은 리눅스 | 빌드는 Actions 통과, 리눅스에서 같은 방식 확인 |
| 안드로이드 런처 "이름" 바꾸기 | 안드로이드는 설치 후 런처 이름을 바꿀 수 없음 | 아이콘은 바뀜, 앱 안 이름·알림 제목은 바뀜 |
| 외부 음성 서비스 | 지시대로 "준비 중" 유지 | 기기 내장 음성 |
| 아이폰 | 지시대로 준비 중 | |
