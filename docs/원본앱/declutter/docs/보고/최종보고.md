# 최종 보고 — 집안 물건 비우기 판매 폐기 비서

## 한 줄 요약
지시서의 1~3단계 기능을 모두 만들었고, 테스트 142개와 리눅스 실제 실행을 통과했습니다.
안드로이드·윈도우·맥 앱 파일은 GitHub Actions가 자동으로 만듭니다(README 1번 참고).

## 완성한 기능
**등록**: 사진(카메라·앨범·파일 여러 장), 방 전체 영상(2초 간격 장면 → AI 인식, 진행률·취소), 이름만 적기,
제미나이 정리 글(공유하기·붙여넣기·txt/csv 파일), 말로 설명하기. AI가 찾은 결과는 고치고·빼고·추가한 뒤 등록.

**분류(딱 세 가지)**: 홈 "오늘 할 일" 카드(하루 한 개), 정리하기 스와이프(←폐기·판매→·↑지금 쓰는 것) + 버튼 + 음성,
AI 추천과 이유, 애매하면 질문 3개로 결정, 되돌리기.

**판매**: 판매글(제목·설명·카테고리) 작성과 복사, AI 시세 범위(최종 가격은 사용자), 판매중·예약·판매완료,
14일마다 10% 인하 추천(설정 가능), 번개장터 택배 안내, 1년 안 팔리면 7일 전 알림 → 폐기로 이동(되돌리기 가능).

**폐기**: 종류별 분리수거, 지역별 대형폐기물 신고 순서와 예상 수수료(구청 확인 권장), 나눔·기부 추천,
디지털로 남기고 버리기(3번 앱 폴더).

**진행 현황**: 큰 숫자·진행 막대, 판매 수입·예상 가치, 음성으로 듣기, 타임랩스(이어 보기 + 엔딩 크레딧 → 1번 앱 폴더).

**음성**: 설명·분류·사연 녹음(말→글, 1번 앱 폴더), 읽어주기(켜기/끄기·속도), 매일 아침 알림 + 음성 안내.
마이크가 안 되는 기기(리눅스 등)는 글자 입력칸으로 자동 대체.

**편의·안정성**: 첫 실행 마법사, 글씨 3단계, 밝게·어둡게·고대비, 3D 아이콘·마스코트·움직임(줄이기 가능), 진동·소리,
여러 사용자, AI 비용(장당 예상·이번 달·누적·월 한도), 밀린 알림, 전역 오류 처리, 문제 신고, 데이터 버전 자동 변환,
암호화 백업·복원(사진 포함), 2번 확인 초기화, 버전 표시, 한국어 글꼴 내장.

## 검증 결과
- 코드 검사·형식 검사 통과, 테스트 142개 통과
  - 흐름 테스트: 사진 등록 → 음성 설명 → 추천 → 확정 → 판매글 → 가격 인하 알림 → 1년 경과 폐기 이동 → 현황 (가짜 날짜)
  - 디자인 테스트: 16개 화면 × (가장 큰 글씨·360×640·밝게/어둡게/고대비, 큰 화면) 넘침 없음, 대비 검사(WCAG AA), 움직임 줄이기
- 리눅스: 이 환경에서 빌드하고 가상 화면에서 실제로 실행해 확인
- GitHub Actions: 검사·테스트·리눅스·안드로이드·윈도우·맥 모두 ✅
- 안전 체크리스트: `docs/검증/3단계.md` (자동 게시 코드 없음, 사진 전송은 동의 시만, 키 기록 안 함 등)

## 못 한 것과 이유
| 항목 | 이유 | 대신 한 것 |
|---|---|---|
| 지메일 자동 읽기 | 구글 로그인(OAuth) 앱 등록·심사가 필요 | 공유하기·붙여넣기·파일 가져오기, 설정에 "준비 중" |
| 외부 음성 서비스 교체 | 서비스 계약·키가 없음 | 교체 가능한 구조(`VoiceIO`)만, 설정에 "준비 중" |
| Lottie 애니메이션 파일 | 라이선스가 확실한 파일을 확보 못 함 | 같은 효과를 코드 애니메이션으로 |
| 영상 → MP4 타임랩스 | 기기 안 영상 인코더 추가 필요 | 움직이는 그림(GIF) + 엔딩 크레딧 |
| 아이폰 | 지시서대로 구조만 | 설정에 "아이폰 지원(준비 중)" |
| 실제 기기 카메라·마이크 시험 | 이 환경에 장치 없음 | 사진 파일·글자 입력으로 같은 흐름 시험 |
| 앱 서명 | 개인 인증서 필요 | 안드로이드는 디버그 서명, 맥은 "오른쪽 클릭 → 열기" 안내 |

## 사용자가 처음 할 일
1. GitHub 저장소 → **Actions** → 최신 "빌드와 테스트" → 맨 아래에서 내 기기용 파일 받기 (README 1번)
2. 앱을 열고 마법사에서 글씨 크기 → 허락 → 사는 지역 → "연습 모드로 시작"
3. 홈의 큰 동그라미 버튼으로 첫 물건 찍기, "오늘 할 일"에서 하나 정하기
4. 실제 AI를 쓰려면: Anthropic(Claude) 사이트에서 API 키 발급 → 설정 → AI 연결에 키 입력, "사진을 AI로 보내기" 켜기, 월 한도 정하기
   (사진 한 장당 약 30원 예상, 설정 화면에 실제 사용액 표시)

## 판매(배포)하려면 할 일
1. **앱 이름·아이콘** 확정 (지금 아이콘은 Flutter 기본)
2. **서명**: 안드로이드 업로드 키 만들기(키 파일은 저장소에 올리지 말 것), 맥·윈도우 코드 서명 인증서
3. **스토어 등록**: 구글 플레이 개발자 계정, 개인정보 처리방침 페이지(사진이 사용자 동의 시 AI로 전송됨을 명시)
4. **AI 키 방식 결정**: 지금은 사용자가 자기 키를 넣는 방식. 판매용이라면 회사 서버를 두고 서버가 AI를 부르는 방식 권장(키 노출 방지, 요금 관리)
5. 대형폐기물 수수료·분리수거 안내를 지역 공식 자료로 갱신하는 절차 마련
6. 지메일·외부 음성 연동이 필요하면 각각 구글 OAuth 심사, 음성 서비스 계약
