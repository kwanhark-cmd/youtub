# 막힌 것 (BLOCKERS)

| # | 내용 | 상태 / 대안 |
|---|---|---|
| 1 | Flutter·안드로이드 SDK가 이 환경에 없음 | 웹 화면 + Electron/Capacitor로 대체(DECISIONS 1). 안드로이드·맥 앱 빌드는 GitHub Actions에서 시도(`continue-on-error`) |
| 2 | 윈도우 실제 PC에서의 설치·실행은 이 환경에서 확인 불가 | GitHub Actions 윈도우 작업에서 설치 파일을 만들고 실행 파일이 켜지는지 자동 확인 |
| 3 | cdn.jsdelivr.net 접속 차단 | 글꼴은 GitHub 원본 저장소에서 받음(해결) |
| 4 | 실제 한글(HWP) 샘플 파일을 만들 한컴 프로그램 없음 | 시험용 OLE 파일 작성기를 직접 만들어 HWP 구조(압축·비압축·긴 레코드·컨트롤 문자)를 시험. 실제 사용자 파일로 추가 확인 권장 |
| 5 | 얼굴·장면 실제 모델 파일(수백 MB)을 이 환경에서 쓰지 않음 | 모델을 넣으면 켜지는 구조 + 시험용 가짜 모델로 흐름 검증. 설치법 `docs/모델설치.md`. 실제 정확도는 사용자 PC에서 확인 필요 |
| 6 | 윈도우 실행 파일이 GitHub Actions에서 첫 시도에 켜지지 않음 | **해결**: 창 없는 실행 파일에서 uvicorn 로그 설정이 문제 → 끄고 재시도, 설치 파일(약 30MB) 생성·실행 확인 통과 |
| 7 | 실제 구글 계정·OAuth 클라이언트로 연결 시험 불가 | 가짜 구글 응답으로 가져오기 흐름 시험. 사용자는 구글 클라우드 콘솔에서 '데스크톱 앱' OAuth 클라이언트를 만들어 설정에 입력(최종보고에 방법) |

## 수정 지시서(1.1.0)
| # | 내용 | 상태 / 대안 |
|---|---|---|
| 8 | 안드로이드 **설치한 앱(APK)**의 런처 이름·아이콘을 앱 안에서 바꾸기 | 런처 아이콘은 앱을 만들 때 고정돼 실행 중에 못 바꿈(바꾸려면 아이콘별 별칭을 미리 넣은 앱을 새로 만들어야 함). 대신 **크롬 '홈 화면에 추가'**는 설정에서 바꾼 이름·아이콘으로 만들어짐(엔진이 앱 정보를 바꿔서 제공). 앱 안 이름·색은 바로 반영 |
| 9 | 윈도우 트레이 아이콘·자동 실행(레지스트리)은 이 리눅스 환경에서 직접 볼 수 없음 | 코드와 설치 파일에 포함, 진행률 문구는 자동 시험. 실제 PC에서 확인 필요 |

| 11 | 업데이트 확인은 GitHub Releases를 로그인 없이 읽음 | 지금 저장소는 **공개**라 동작함(확인). 나중에 비공개로 바꾸면 업데이트 확인이 안 되므로 판매 시 공개 배포 주소 유지 필요 |
