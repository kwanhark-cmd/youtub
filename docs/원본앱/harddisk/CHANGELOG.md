# 바뀐 점 (변경 내역)

새 버전 설치는 **덮어쓰기**입니다. 색인·설정·얼굴 이름·메모·인맥은 그대로 남아요.

## 1.1.0
- **업데이트 확인** 버튼(설정 맨 위): 새 버전을 알려주고, 누르면 내려받아 설치해요. 분석 중에는 끝난 뒤 하도록 안내해요. 설치 전에 설정·인물 정보를 자동 백업해요.
- 자료 위치를 설정 화면에 표시하고, 다른 드라이브로 옮길 수 있어요(원래 자료는 그대로 둠).
- 화면 새 디자인: 큰 검색창, 오늘의 추억 큰 카드, 사람 얼굴 줄, 종류별 색(사진 파랑·영상 보라·문서 주황·일기 초록·사람 분홍)
- 긴 목록도 빠르게(보이는 것만 그리기), 갱신돼도 보던 위치 유지
- 상태 표시(색인·얼굴 모델·구글·엔진 연결)를 따로 보여줘요. 모든 오류 창에 '문제 신고' 버튼
- 얼굴 인식: 상업적으로도 쓸 수 있는 기본 모델(OpenCV YuNet·SFace)을 버튼 한 번으로 설치
- 구글 연결 도우미(단계별 안내, JSON 파일 불러오기)
- 앱 꾸미기: 표시 이름·아이콘·색 테마
- 윈도우: PC 시작 시 자동 실행(기본 켜짐), 작업 표시줄 알림 영역에 진행률 아이콘
