# 작업 계획 (PLAN)

"컴퓨터 하드 자료 검색 정리 비서"를 아래 순서로 만듭니다. 각 단계는 **구현 → 자체 검증 → 오류 수정 → 커밋 → 보고** 순서입니다.

## 구조
| 부분 | 기술 | 위치 |
|---|---|---|
| 분석 엔진 (윈도우 PC) | Python 3.11+, FastAPI, SQLite + FTS5 | `engine/hdbiseo/` |
| 보기 화면 | 웹 화면(HTML/CSS/JS, 빌드 불필요) — 엔진이 직접 제공 | `web/` |
| 데스크톱 포장 | Electron (윈도우·맥) | `desktop/` |
| 안드로이드 포장 | Capacitor (GitHub Actions에서 빌드) | `desktop/` 설정 공유 |
| 윈도우 설치 프로그램 | PyInstaller + Inno Setup (GitHub Actions) | `.github/workflows/` |

## 단계
1. **1단계** 전체 목록과 검색 + 문서 내용 검색: 폴더 선택·제외, 읽기 전용 색인, 이어서 하기, 증분, 밤 시간 실행, 연결 끊김 대응, 읽을 수 없음 목록, 이름·날짜·종류·크기·위치 검색, HWPX·HWP·DOCX·XLSX·PDF·TXT 내용 검색과 문장 미리보기, 첫 실행 마법사, 홈 화면, 설정, 로그·문제 신고, 백업·복원·초기화
2. **2단계** 사진·영상 날짜별 보기: EXIF 촬영일·장소, 썸네일 캐시(용량 한도), 연·월 타임라인, N년 전 오늘, TV 상영관, 장소별 보기
3. **3단계** 얼굴 인식·장면 꼬리표: 모델을 넣으면 켜지는 구조, 사람 묶기·이름 붙이기·두 사람 합치기, 장면 검색과 해당 시각 재생, 장면 모음·내보내기 폴더, 목소리 구간 모음
4. **4단계** 중복 파일 찾기: 크기→해시, 휴지통으로 이동(2단계 확인)
5. **5단계** 개인 기록 통합과 인맥 지도: 구글 캘린더·주소록(OAuth, 설정에서), .ics/.vcf 가져오기, 구글 킵 테이크아웃, 워드 일기장, 음성 일기·음성 메모, 통합 타임라인, 사람 연결, 인맥 지도

## 공통
- 음성 검색·읽어주기·음성 메모·음성 일기 (브라우저 내장 음성 기능, 안 되면 글자 입력칸)
- 여러 사용자(로컬 계정별 별도 색인), 외부 AI(기본 꺼짐), 다른 기기 접속(기본 꺼짐, 연결 번호 필요)
- 테마 한 파일(`web/theme.css`), 밝은·어두운·고대비, 글씨 3단계, 움직임 줄이기

## 검증
- `engine/tests` (pytest) — 이 환경에서 테스트 폴더로 실제 실행
- `web/tests` (Playwright) — 흐름 점검, 360×640·가장 큰 글씨·어두운·고대비에서 잘림 검사, 대비 검사, 움직임 줄이기
- GitHub Actions — 윈도우·맥 테스트와 설치 프로그램 빌드
