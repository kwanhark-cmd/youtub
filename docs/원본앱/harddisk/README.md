# 컴퓨터 하드 자료 검색 정리 비서

윈도우 PC에 연결된 큰 하드디스크들(예: 10TB × 5개)의 **사진·영상·문서를 한곳에서 찾아 주는 프로그램**입니다.
일기·메모·구글 일정·연락처까지 **한 검색창**에서 찾을 수 있어요.

- 하드디스크의 파일은 **절대 바꾸거나 옮기지 않아요.** 목록(색인)만 만들어요.
- 지우기는 내가 직접 누르는 **'휴지통으로 이동'** 하나뿐이고, 휴지통에서 언제든 되살릴 수 있어요.
- 모든 분석은 **내 PC 안에서만** 해요. 인터넷으로 보내지 않아요(AI 연결을 직접 켤 때만 예외).

---

## 1. 윈도우 PC에 설치하기
1. `HDBiseo-Setup-1.0.0.exe` 를 내려받아 두 번 누릅니다.
   (만드는 곳: 이 저장소의 GitHub → **Actions** → 가장 최근 "검사와 빌드" → 아래 **HDBiseo-Windows-Setup**)
2. "다음"을 눌러 설치합니다. 원하면 **"컴퓨터를 켤 때 자동으로 시작(밤 색인용)"** 에 체크하세요.
3. 바탕화면의 **하드 자료 찾기 비서** 아이콘을 누르면 인터넷 창에 프로그램 화면이 열립니다.

## 1-1. 새 버전 설치(업데이트) — 색인·설정은 그대로
- **설정 맨 위 → "업데이트 확인"** 을 누르면 새 버전이 있는지 알려주고, "지금 설치"를 누르면 내려받아 설치해요.
- 또는 새 `HDBiseo-Setup-x.y.z.exe` 를 받아 그냥 실행하면 됩니다. **덮어쓰기 설치**예요.
- 며칠 걸려 만든 **색인·썸네일·설정·얼굴 이름·메모·인맥**은 프로그램 폴더가 아니라 **자료 폴더**
  (`C:\Users\(내 이름)\AppData\Local\HDBiseo`, 설정 화면 '자료 위치'에 표시)에 있어서 업데이트로 사라지지 않아요.
- 색인 형식이 바뀌는 버전이면 **자동으로 변환**하고(다시 분석하지 않음), 변환 전에 색인을 자동 백업해요.
- 설치 전에는 설정·인물 정보를 자동으로 백업해요. 분석(색인) 중에는 "분석이 끝난 뒤 해 주세요"라고 안내해요.
- 맥·안드로이드 보기 앱도 같은 버튼으로 새 앱을 내려받을 수 있어요. PC 엔진과 버전이 다르면 알려줘요.

## 2. 처음 설정 (화면이 순서대로 안내해요)
1. **글씨 크기** 고르기 (보통 / 크게 / 아주 크게)
2. **하드디스크 고르기** — "하드디스크·폴더 추가"를 눌러 D:, E: 같은 하드를 고릅니다. 빼고 싶은 폴더는 "제외 폴더"로 지정.
   *먼저 체험해 보고 싶으면 "체험용 예제 폴더로 해보기"를 누르세요.*
3. **밤에만 색인할지** 고르기
4. **예상 시간**을 확인하고 "색인 시작하기"
   - 목록이 만들어지는 대로 바로 검색할 수 있어요.
   - 중간에 꺼져도, 하드를 뺐다 꽂아도 **이어서** 해요.

## 3. 맥·안드로이드에서 보기 (같은 와이파이 안에서만)
1. PC 화면에서 **설정 → 다른 기기에서 보기 → 켜기**, 그리고 프로그램을 한 번 껐다 켭니다.
2. 설정 화면에 나온 **주소**(예: `http://192.168.0.10:47810`)를 휴대폰·맥의 인터넷 창(크롬·사파리)에 입력합니다.
3. 처음 한 번 **6자리 연결 번호**를 입력하면 끝.
4. 연결이 안 되면 화면에 나오는 안내(같은 와이파이인지, PC가 켜져 있는지)를 확인하고 **"다시 찾기"** 를 누르세요.
   - 맥 전용 앱(HDBiseo-Mac)과 안드로이드 앱(HDBiseo-Android)도 GitHub Actions에서 만들어집니다. 앱은 같은 와이파이의 PC를 자동으로 찾아요.
- 아이폰은 아직 "준비 중"입니다(사파리로 주소 접속은 가능).

## 4. 권장 PC 사양
| | 최소 | 권장(사진 수십만 장) |
|---|---|---|
| 운영체제 | 윈도우 10 (64비트) | 윈도우 11 |
| 메모리 | 8GB | **16GB 이상** |
| 그래픽카드 | 없어도 됨(얼굴·장면 인식이 느림) | 엔비디아 GeForce 계열 |
| 색인 저장 공간 | 파일 100만 개당 약 1GB + 썸네일(설정에서 한도) | SSD |

처음 색인은 하드 크기에 따라 몇 시간~며칠 걸릴 수 있어 **밤에 돌리기**를 권해요. 화면에서 예상 시간을 알려줘요.

## 5. 얼굴 인식·장면 찾기 켜기 (선택)
얼굴·장면 인식은 PC 안에서 돌아가는 공개 모델을 쓰며, **모델 파일을 넣으면 켜집니다.** 자세한 방법은 `docs/모델설치.md`.

## 6. 문제가 생기면
- **설정 → 문제 신고 파일 만들기** 를 눌러 만든 파일을 보내 주세요(파일 내용·연락처·일기는 들어가지 않아요).
- 색인이 이상하면 **설정 → 백업·복원·초기화** 에서 이전 백업으로 되돌리거나 초기화할 수 있어요(하드의 파일은 그대로).

## 개발자용
```
engine/      분석 엔진(Python, FastAPI, SQLite FTS5)
web/         보기 화면(HTML·CSS·JS, 빌드 없음). theme.css = 색·크기·움직임 한 파일
desktop/     Electron(윈도우·맥) + Capacitor(안드로이드) 포장
scripts/     100만 개 속도 측정 등
docs/보고    단계별 보고 / docs/검증 단계별 검증
```
- 엔진 실행: `cd engine && pip install -r requirements.txt && python -m hdbiseo`
- 엔진 테스트: `cd engine && pip install -r requirements-dev.txt && python -m pytest -q`
- 화면 테스트: `npm i playwright && node web/tests/ui-test.js`
- 체험용 샘플 폴더: `cd engine && python -m hdbiseo.samples 샘플폴더`
- 100만 개 속도: `python scripts/bench_million.py`
