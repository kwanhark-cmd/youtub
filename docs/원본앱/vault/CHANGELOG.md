# 변경 내역

## [1.1.0]
### 새로 생긴 것
- **업데이트 확인**: 설정 맨 위에서 새 버전을 확인하고, 금고를 자동 백업한 뒤 내려받아 설치(파일 해시 확인, 다르면 설치 중단)
- 화면 새 디자인: 이번 달 구독료 큰 숫자, 오늘 할 일, 이번 주 결제 예정, 서비스 색 아이콘, 색이 채워진 카드
- 지메일·AI·생체 인증 상태를 홈과 설정에 따로 표시
- 지메일 연결 단계별 도우미, 구글 JSON 파일 불러오기, AI 열쇠 파일 불러오기
- 앱 꾸미기: 표시 이름, 색 테마, 눈에 안 띄는 "위장" 이름·아이콘(계산기·메모)
- 크레딧 "내일 다시 알림" 버튼
- 오류 창에서 "다시 시도"와 "문제 신고"
### 고친 것
- 목록을 보다가 자동 잠금·알림이 와도 보던 화면·위치로 돌아옴
- 실패 창을 닫은 뒤 "다시 시도"할 때 앱이 멈출 수 있던 문제 차단
- 사용자 목록 파일이 지워져도 금고를 다시 찾아 열 수 있음
### 그대로인 것
- 금고 파일 형식·위치·암호화 설정은 1.0.0 과 같습니다. 기존 마스터 비밀번호로 그대로 열립니다.
