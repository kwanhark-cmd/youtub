# 개발 계획 (PLAN)

앱 이름: **로그인 계정과 구독 결제 관리 비서** (코드 이름 `account_vault`)

## 기술
- Flutter 3.47.9 (안드로이드·윈도우·맥·리눅스). 아이폰은 구조만 열어 둠.
- 암호화: `cryptography` 패키지(검증된 표준 구현)의 AES-256-GCM + Argon2id. 직접 만든 암호 없음.
- 저장: 기기 안의 암호화 파일 금고(사용자마다 폴더 분리). 자세한 이유는 DECISIONS.md.
- 결제 메일 분석: Claude API(직접 HTTP 호출), 키가 없으면 규칙 분석·수동 입력.

## 순서 (각 단계: 구현 → 자체 검증 → 오류 수정 → 커밋 → 보고)

### 0단계 — 기반
- [x] Flutter 설치, 프로젝트 생성, 의존성 버전 고정
- [x] 금고: 키 생성(Argon2id), 암호화(AES-GCM), 마스터 비밀번호·복구 코드·기기 키 래핑
- [x] 잠금/해제, 실패 반복 시 지연, 자동 잠금, 사용자별 분리
- [x] 금고 테스트(왕복, 틀린 비밀번호, 손상 파일, 복구 코드 1회용, 지연)

### 1단계 — 구독·만료 알림
- [x] 데이터 모델·버전 변환, 백업 내보내기/가져오기(검사 + 자동 백업 후 복원)
- [x] 구독 목록·추가·수정, 월/연 총액, 이번 달 결제 타임라인, 카드 끝 4자리만
- [x] 크레딧·체험판 만료 등록, 7일·1일 전 알림, 갱신 전 알림, 밀린 알림
- [x] 첫 실행 마법사, 잠금 화면, 홈(오늘 할 일·큰 타일), 설정, 테마 파일 하나
- [x] 음성 질문·명령·아침 브리핑(기기 음성, 안 되면 글자 입력), 비밀번호는 절대 읽지 않음
- [x] 결제 메일 분석(규칙 + Claude), 지메일 읽기 전용 연결(설정에서)
- [x] 구글 비밀번호 관리자 CSV 가져오기
- [x] 로그(비밀정보 가림), 문제 신고 내보내기, 전역 오류 처리
- [x] 디자인 테스트(가장 큰 글씨·360×640·어두운·고대비), 대비 검사

### 2단계 — 해지 추천·계정 정리
- [x] 마지막 사용일, 해지 후보, 중복 구독 알림, 해지 방법 안내
- [x] 계정 목록(서비스·아이디·가입 이메일·용도·변경일), 로그인 페이지 바로가기
- [x] 금고 건강 보고서(재사용·약한·오래된 비밀번호), 유출 확인(켤 때만, 해시 앞 5글자만)

### 3단계 — 비밀번호 보관·생성
