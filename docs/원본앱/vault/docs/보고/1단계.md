# 1단계 보고 — 금고·구독 지출·만료 알림 (+ 공통 기반)

## 만든 것
| 기능 | 상태 | 위치 |
|---|---|---|
| 암호화 금고(AES-256-GCM, Argon2id, 키 저장 안 함) | 완료 | `lib/core/crypto`, `lib/core/vault` |
| 마스터 비밀번호·복구 코드(1회용)·생체 인증 키 | 완료 | `lib/core/vault/vault.dart` |
| 실패 반복 시 지연, 자동 잠금(기본 2분), 백그라운드 복귀 잠금 | 완료 | `vault.dart`, `lib/app/app_controller.dart` |
| 여러 사용자(금고 폴더 완전 분리) | 완료 | `lib/data/repository.dart` |
| 구독: 월 요금·결제일·카드 끝 4자리·다음 갱신일, 월·연 합계(달러 환산), 이번 달 결제 예정표 | 완료 | `lib/logic/money.dart`, `dates.dart`, `ui/screens/subscriptions_screens.dart` |
| 만료 알림: 크레딧·체험판 7일 전·1일 전, 구독 결제 N일 전, 밀린 알림, 개인 정보 없는 OS 알림 | 완료 | `lib/logic/alerts.dart`, `app/platform_services.dart` |
| 결제 메일 분석(규칙 + Claude API), 지메일 읽기 전용 연결, 메일 붙여넣기 | 완료(실제 지메일 계정 연결은 사용자가 할 일) | `lib/logic/mail_analysis.dart`, `gmail.dart` |
| 구글 비밀번호 관리자 CSV 가져오기 | 완료 | `lib/logic/csv_import.dart` |
| 음성 질문·명령·아침 브리핑(비밀번호 절대 안 읽음, 변경 전 확인) | 완료 | `lib/logic/voice_assistant.dart`, `ui/screens/voice_screen.dart` |
| 첫 실행 마법사, 잠금 화면, 홈(오늘 할 일·큰 숫자·3D 타일), 설정 | 완료 | `lib/ui/screens` |
| 백업 내보내기·가져오기(검사 → 비밀번호 확인 → 현재 데이터 자동 백업 → 복원) | 완료 | `repository.dart` `BackupService` |
| 로그(비밀정보 가림)·문제 신고·전역 오류 처리·데이터 버전 변환·초기화·버전 표시·한국어 글꼴 | 완료 | `lib/core/log`, `lib/data/migrations.dart`, `main.dart` |

## 자체 검증 결과
- `flutter analyze`: 문제 없음 / `dart format`: 통과
- `flutter test`: 전체 통과(금고 12, 로직·음성·가져오기·백업 47, 흐름 9, 화면 흐름 2, 디자인 26 등)
- 리눅스 빌드: 이 환경에서 성공, 실제 실행해 화면 확인(Xvfb)
- GitHub Actions: 테스트·리눅스·안드로이드·윈도우·맥 모두 성공(윈도우는 1차 실패 → 원인 수정 후 성공)

## 검증 중 발견해 고친 오류(재발 방지 테스트 포함)
1. **잠글 때 클립보드 정리를 기다리느라 키가 잠깐 남아 있던 문제** → 키를 즉시 버리고 클립보드는 나중에 정리. (`controller_flow_test` "백그라운드에 오래 있다 돌아오면 잠김")
2. **가장 큰 글씨에서 구독 카드·결제 예정표가 오른쪽으로 넘침** → 이름과 금액을 위아래로 배치. (`design_test`)
3. **잠금 화면이 사용자 정보를 불러오기 전에 "열기"를 누르면 반응 없음** → 기본 사용자로 처리. (`flow_ui_test`)
4. **윈도우 빌드 실패**(local_auth_windows 플러그인이 최신 Visual Studio 에서 막힘) → 컴파일 옵션 추가. (CI)
5. 카드번호 가리기 정규식이 뒤 공백까지 먹던 문제. (`import_backup_test`)
6. 만료 후 오래된 크레딧이 "오늘 할 일"에 계속 남던 문제 → 만료 14일 후부터 알림 중단.
