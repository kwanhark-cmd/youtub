# 2단계 보고 — 해지 추천·SNS 계정 정리

## 만든 것
| 기능 | 상태 | 위치 |
|---|---|---|
| 마지막 사용일 기록("오늘 썼어요"), 오래 안 쓴 구독 질문("아직 써요"/"해지 후보로") | 완료 | `lib/logic/cleanup.dart`, `ui/screens/cleanup_screens.dart` |
| 해지 후보 목록 + 해지하면 아끼는 월 금액 | 완료 | 정리 도우미 화면 |
| 비슷한 기능 구독 중복 알림(AI 대화, AI 영상, 디자인, 영상 보기 등) | 완료 | `services_catalog.dart` 묶음 |
| 해지 방법 안내 + 결제 관리 페이지 바로가기(해지는 사용자가 직접) | 완료 | 구독 상세 화면 |
| 결제일 전 알림이 해지 후보면 빨강으로 강조 | 완료 | `alerts.dart` |
| 계정: 서비스·아이디·가입 이메일·연결 채널/용도·2단계 인증·마지막 비밀번호 변경일 | 완료 | `accounts_screens.dart` |
| 로그인 페이지 바로가기(알려진 서비스는 자동) | 완료 | 계정 상세 |
| **"이 구독의 로그인 계정"** 바로 연결(이름이 같으면 자동 연결) — 이 앱의 차별점 | 완료 | 구독 상세 ↔ 계정 상세 |
| 금고 건강 보고서(재사용·약한·오래된·미등록), 점수 | 완료 | `HealthScreen` |
| 유출 확인(사용자가 켤 때만, 해시 앞 5글자만 전송) | 완료 | `lib/logic/breach.dart` |
| 한국어 별명 인식(넷플릭스↔Netflix, 힉스필드↔Higgsfield, 카톡↔카카오톡 …) | 완료 | `services_catalog.dart` |

## 자체 검증
- 단위 테스트: 오래 안 쓴 구독·중복 묶음·건강 보고서(결과에 비밀번호 미포함)·유출 확인(전송 값 검사) 통과
- 디자인 테스트: 정리 도우미·건강 보고서·계정 화면을 가장 큰 글씨/360×640/어두운/고대비에서 검사 통과

## 참고
- 해지 페이지 주소는 서비스 쪽에서 바뀔 수 있어 화면에 "주소가 바뀌었을 수 있어요"를 함께 표시하고,
  구독마다 주소를 직접 고칠 수 있게 했습니다.
