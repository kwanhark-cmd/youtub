# 3단계 보고 — 비밀번호 보관과 생성

## 만든 것
| 기능 | 상태 |
|---|---|
| 사이트별 비밀번호 암호화 보관(금고 전체가 AES-256-GCM) | 완료 |
| 보기/숨기기, 복사 → **30초 원형 카운트다운 후 클립보드 자동 삭제** (그사이 다른 것을 복사했으면 건드리지 않음, 잠그면 즉시 삭제) | 완료 |
| 비밀번호 생성기(안전한 난수, 8~40자, 대문자·숫자·기호 선택, 헷갈리는 글자 제외, 고른 종류 반드시 포함) | 완료 |
| 계정 입력 화면에서 바로 "튼튼한 비밀번호 새로 만들기", 강도 표시 | 완료 |
| 비밀번호 바꾸면 변경일 자동 기록(오래된 비밀번호 판단에 사용) | 완료 |
| 자동 채우기(안드로이드 자동완성·브라우저 확장) | **설계만** — `docs/다음단계.md` |
| 다른 앱(1번 앱)이 사용자 승인 후 비밀번호를 받는 연결 | **설계만** — `docs/다음단계.md` |

## 자체 검증
- 생성기 테스트(길이·종류·무작위·강도), 클립보드 30초 테스트(가짜 시계), 전체 흐름 테스트(생성 → 복사 → 자동 삭제) 통과
- 디자인 테스트: 비밀번호 만들기·계정 상세 화면 통과
