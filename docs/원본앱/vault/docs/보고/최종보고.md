# 최종 보고 — 로그인 계정과 구독 결제 관리 비서

## 한 줄 요약
지시서 1~3단계를 모두 만들고, 자동 테스트 95개·린트·형식 검사·리눅스 실행을 통과했으며,
GitHub Actions 에서 안드로이드 APK·윈도우·맥·리눅스 앱 빌드가 모두 성공했습니다.

## 완성된 기능
- **금고**: AES-256-GCM 암호화, 마스터 비밀번호에서 Argon2id 로 키 생성(키·비밀번호는 저장 안 함), 복구 코드(1회용), 지문·얼굴(실패하면 마스터 비밀번호), 여러 번 틀리면 대기, 2분 자동 잠금, 사용자별 금고 분리
- **구독 결제**: 월 요금·결제일·카드 끝 4자리·다음 결제일, 한 달·1년 총액(달러 환산), 이번 달 결제 예정표, 결제 전 알림
- **만료 알림**: 크레딧·체험판 7일 전·1일 전, OS 알림(개인 정보 없음) + 앱을 열면 놓친 알림을 화면·소리로
- **메일로 채우기**: 영수증 붙여넣기 → 자동 분석(무료) / Claude AI(키 있을 때, 비용 안내·월 한도) / 지메일 읽기 전용 연결
- **정리 도우미**: 오래 안 쓴 구독, 비슷한 구독 중복, 해지 후보와 아낄 금액, 해지 방법·페이지 바로가기
- **계정·비밀번호**: 아이디·가입 이메일·용도·2단계 인증·변경일, 로그인 페이지 바로가기, "이 구독의 로그인 계정" 연결, 비밀번호 생성기, 복사 후 30초 자동 삭제(원형 카운트다운)
- **금고 건강 보고서**: 재사용·약한·오래된 비밀번호, 점수, 유출 확인(켤 때만, 비밀번호 미전송)
- **음성 비서**: 질문·명령·아침 브리핑, 변경은 "네/아니요" 확인 후, 비밀번호는 절대 읽지 않음
- **기타**: 구글 비밀번호 관리자 CSV 가져오기, 암호화 백업·복원(검사 + 자동 백업), 글씨 3단계, 밝게·어둡게·고대비, 움직임 줄이기, 진동·소리, 문제 신고 기록(비밀 미포함), 3D 이모지·마스코트, 한국어 글꼴, 안드로이드 화면 캡처 방지

## 사용자가 처음 할 일
1. GitHub → Actions → "검사와 빌드" 최근 성공 실행 → Artifacts 에서 기기에 맞는 파일 내려받아 설치 (README 1번)
2. 앱 첫 화면 안내대로 **마스터 비밀번호**를 정하고 **종이에 적어** 안전한 곳에 보관
3. **복구 코드**를 종이에 옮겨 적거나 인쇄해 마스터 비밀번호와 **다른 곳**에 보관 ("적어 두었습니다" 체크해야 진행)
4. 구독을 몇 개 직접 넣어 보거나, 결제 메일을 붙여 넣어 "메일로 채우기"
5. (선택) 구글 비밀번호 관리자 CSV 가져오기 → 가져온 CSV 파일은 바로 삭제
6. (선택) 설정 → AI 연결 / 지메일 연결 (README 3·4번)
7. 가끔 설정 → 백업 → 백업 파일 만들기 → USB·PC 에 보관

## 판매 전 보안 점검 항목 (요약, 자세히는 `docs/배포준비.md`)
1. **외부 전문 업체 보안 점검**(암호화 사용법, 메모리 잔류, 파일 변조, 클립보드, 로그)
2. 생체 인증 키를 OS 생체 인증에 묶는 방식으로 강화
3. 윈도우·맥 화면 캡처 방지 추가, 안드로이드 클립보드 "민감 내용" 표시
4. 지메일 민감 범위 구글 앱 검수, 개인정보처리방침(AI·지메일 전송 내용 명시)
5. 각 플랫폼 정식 서명(안드로이드 업로드 키, 윈도우 코드 서명, 맥 공증)
6. 의존성 취약점 정기 검사, 실제 기기 시험
