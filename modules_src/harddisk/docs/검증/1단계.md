# 1단계 검증

실행 방법: `cd engine && python -m pytest -q` / `node web/tests/ui-test.js`

## 자동 테스트 결과
- 엔진: **38개 통과** (이 환경, 파이썬 3.13)
- 화면: **흐름 13개 + 디자인 4종 + 움직임 줄이기 + 화면 오류 없음 — 모두 통과**
  - 흐름: 첫 실행 → 글씨 크기 → 폴더 고르기 창 → 체험 폴더 추가 → 밤 시간 → 예상 시간 → 색인 → 이름 검색 → 내용 검색(강조) → **음성 검색(마이크 흉내)** → 날짜별 보기 → 추억·장소·상영관 → 말로 메모 → **중복 찾기 → 휴지통 확인 창 2단계 → 취소하면 파일 그대로**
  - 음성 인식이 없는 기기 → 마이크 버튼 대신 글자 입력칸만
- 린트(ruff) 통과

## 안전 체크리스트
| 항목 | 결과 | 확인 방법 |
|---|---|---|
| 원본을 쓰기·이동·삭제하는 코드가 없는가 | ✅ | `tests/test_safety.py`가 위험한 호출을 모두 찾아 허용 목록(앱 폴더 전용)과 비교. 색인 후 샘플 폴더 모든 파일의 크기·수정 시각이 그대로인지 비교(`test_originals_untouched`) |
| 영구 삭제 코드가 없는가 | ✅ | 원본 삭제는 `trash.py`의 send2trash(운영체제 휴지통) 한 곳뿐, `confirm=true` 없으면 거절. 화면은 2단계 확인 |
| 분석 데이터가 외부로 나가지 않는가 | ✅ | 인터넷 호출 코드는 `ai.py`·`google.py`(설정에서 켤 때만)에만 허용 — 자동 점검. 지도도 오프라인 |
| 외부 AI 호출이 설정에 따라 꺼지는가 | ✅(5단계에서 테스트 추가) | 기본값 꺼짐 |
| 큰 폴더에서 중단·재개가 되는가 | ✅ | `test_stop_and_resume_continues`, `test_drive_disconnect_and_reconnect` |
| 모든 문구가 한국어인가 | ✅ | 오류 메시지 한국어 검사(테스트), 화면 문구 전부 한국어 |
| 글씨 크기 조절 적용 | ✅ | 3단계 모두 화면 테스트(가장 큰 글씨 360×640에서 잘림 없음) |

## 디자인 검증
- 가장 큰 글씨 + 가장 작은 화면(360×640), 어두운 모드, 고대비 모드, 넓은 화면 — 12개 화면에서 **가로 넘침·화면 밖·글자 잘림·타일 겹침·버튼 높이(56px)·터치 영역(48px)** 자동 검사 통과
- **글자 대비 WCAG AA(4.5:1) 이상** — 화면의 모든 글자에 대해 실제 계산 통과
- 움직임 줄이기를 켜면 전환·애니메이션 시간 0, 끄면 다시 움직임 — 통과
- 검사 중 실제로 찾아 고친 문제: 설정 화면이 작은 휴대폰에서 옆으로 넘침(시간 입력칸) → 수정 / 고대비 모드에서 '추억 보기' 버튼이 노란 카드와 구분 안 됨 → 전용 색 추가
