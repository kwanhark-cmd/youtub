# 얼굴 인식·장면 인식 모델 (설치·라이선스)

모든 인식은 **PC 안에서만** 해요. 사진이 인터넷으로 나가지 않아요.
모델이 없어도 다른 기능(검색·날짜별 보기·중복 정리·기록·목소리 구간)은 모두 동작합니다.

## 1. 얼굴 인식 — 버튼 한 번으로 켜기 (1.1.0부터)
**설정 → 얼굴 모델 → "얼굴 인식 켜기(모델 내려받기)"** 를 누르면 끝이에요.
1. 기본 얼굴 모델 두 파일(약 39MB)을 OpenCV 공식 저장소에서 내려받아요.
2. 파일이 맞는지 확인(sha256)한 뒤 자료 폴더의 `models\opencv\` 에 넣어요.
3. 곧바로 켜지고, "얼굴 찾기 시작"을 누르면 사진 속 얼굴을 묶기 시작해요.

### 인터넷이 막혀 있을 때(수동 설치)
다른 컴퓨터에서 아래 두 파일을 받아 USB 등으로 옮긴 뒤 **설정 → 얼굴 모델 → 수동 설치 → "모델 파일 불러오기"**로 넣으세요. zip으로 묶어도 돼요.
- `face_detection_yunet_2023mar.onnx` — https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet
- `face_recognition_sface_2021dec.onnx` — https://github.com/opencv/opencv_zoo/tree/main/models/face_recognition_sface

## 2. 라이선스 — 개인 사용 / 판매
| 모델 | 하는 일 | 라이선스 | 판매 제품에 사용 | 이 앱에서 |
|---|---|---|---|---|
| **OpenCV YuNet** (2023mar) | 얼굴 찾기 | MIT | ✅ 가능(저작권 표시) | **기본** |
| **OpenCV SFace** (2021dec) | 얼굴 비교 | Apache-2.0 | ✅ 가능(라이선스 표시) | **기본** |
| InsightFace buffalo_l | 찾기+비교 | 비상업 연구용 | ❌ 상업용 라이선스 구매 필요 | 선택(개인 사용용) |

- 설정의 얼굴 모델 카드에 "개인 사용·판매 모두 가능" / "개인 사용용 — 판매 시 상업용 모델 필요"가 표시돼요.
- **모델 바꾸기**: 설정 → 얼굴 모델 → "쓸 모델"에서 고르기. InsightFace를 쓰려면 `pip install insightface==0.7.3 onnxruntime==1.20.1` 후 buffalo_l zip을 "모델 파일 불러오기"로 넣으세요.

### 조사한 다른 상업용 후보(참고)
| 후보 | 라이선스 | 메모 |
|---|---|---|
| dlib `face_recognition_resnet_model_v1` | 코드 Boost, 모델 공개(작성자가 퍼블릭 도메인 공개 — 판매 전 원문 재확인 권장) | 정확도 좋음, CPU에서 느림, dlib 설치 부담 |
| OpenCV Haar/LBP + SFace | BSD/Apache-2.0 | YuNet보다 찾기 정확도 낮음 |
| MediaPipe Face Detection | Apache-2.0 | 찾기만 가능(같은 사람 비교 모델 없음) |
- 결론: **YuNet(MIT) + SFace(Apache-2.0)** 조합이 가볍고(39MB), 라이선스가 분명하며, OpenCV 하나로 동작해 기본값으로 정했어요.
- 이 환경에서 실제로 확인: 같은 사람(사진과 좌우 뒤집은 사진) 유사도 0.91, 다른 사람 0.13 → 같은 사람 기준 0.38. GitHub Actions에서도 실제 모델로 매번 시험해요.

## 3. 장면 인식 (OpenCLIP) — 수동 설치
장면 인식은 큰 프로그램(torch, 약 800MB)이 필요해서 앱 안 버튼 설치는 아직 없어요.
1. `pip install open_clip_torch==2.29.0 torch==2.5.1`
2. OpenCLIP `ViT-B-32`(laion2b, MIT) 가중치를 `models\clip\open_clip_vit_b32.bin` 이름으로 넣기
3. 다시 켜면 "비 오는 장면", "바닷가" 같은 말로 장면을 찾아요.

## 동작 방식
- 색인의 추가 단계로 돌아가요(목록 → 사진 정보·문서 → 목소리 → 얼굴 → 장면). 하드 상태 화면·트레이 아이콘에서 잠시 멈춤·이어서 가능
- 영상은 장면을 10초마다, 얼굴은 30초마다 한 장씩 봐요(ffmpeg 필요, 윈도우 설치 파일에 포함)
- 그래픽카드가 없으면 느리지만 CPU로도 동작해요
