# 1단계 보고 — 전체 목록과 검색, 문서 내용 검색

## 만든 것
- **분석 엔진**(윈도우 PC에서 돌아가는 프로그램)
  - 고른 하드디스크·폴더를 순서대로 훑어 **파일 목록(색인)** 을 만듭니다. 파일은 읽기만 하고 절대 바꾸지 않습니다.
  - 제외할 폴더를 지정할 수 있습니다. 휴지통·시스템 폴더는 자동으로 건너뜁니다.
  - 폴더 하나를 끝낼 때마다 저장 → **중간에 꺼져도 이어서** 합니다.
  - 두 번째부터는 **새로 생기거나 바뀐 파일만** 다시 분석합니다(지워진 파일은 목록에서 빠짐).
  - **밤 시간에만** 돌리기(예: 23시~6시).
  - 하드디스크가 **분리되면 '연결 끊김'** 으로 표시하고, 다시 꽂으면 이어서 합니다. 목록은 지우지 않습니다.
  - 깨진 파일, 권한 없는 폴더, 아주 긴 경로, 특수문자 이름은 건너뛰고 **'읽을 수 없음' 목록**에 이유와 함께 남깁니다.
- **검색**
  - 파일 이름·폴더 이름, 날짜(연·월·일), 종류(사진·영상·문서·소리, 한글·엑셀·워드·PDF), 크기, 위치로 찾기
  - **문서 안의 글자 검색**: 한글(HWP·HWPX), 엑셀(XLSX), 워드(DOCX), PDF, 글(TXT·CSV), 파워포인트, 옛 워드·엑셀(최선 노력). 찾은 낱말이 들어간 **문장을 미리보기**로 보여주고 노란색으로 강조
  - "2005년 아이들 영상 찾아줘", "계약금 들어간 문서 찾아줘" 같은 **말 그대로의 문장**을 조건으로 바꿔 찾음
  - 100만 개에서도 빠르게: 실제 측정 결과 아래 표
- **보기 화면**: 첫 실행 마법사(글씨 크기 → 하드 고르기·제외 폴더 → 밤 시간 → 예상 시간), 홈(오늘 할 일 카드 + 큰 타일 6개), 찾기(음성 검색·결과 읽어주기), 파일 보기(폴더 열기·원본 열기·기억 메모·휴지통으로 이동), 하드 상태(색 띠·진행 막대·일시정지·이어서), 읽을 수 없음 목록, 문서 화면, 설정
- **오류 대비**: 전역 오류 처리(쉬운 한국어), 로그(파일 내용·연락처 기록 안 함, 전화번호·이메일 자동 가림), 문제 신고 파일 내보내기, 색인 자료 버전과 자동 변환(변환 전 자동 백업), 백업·복원, 초기화(2번 확인, 초기화 전 자동 백업), 버전 표시, 한국어 글꼴 포함, 여러 사용자(가족별 따로)

## 100만 개 파일 검색 속도 (이 환경에서 측정, `scripts/bench_million.py`)
| 검색 | 시간 |
|---|---|
| 이름 '계약서'(3글자) | 125ms |
| 이름 '일기'(2글자) | 103ms |
| 이름 + 2005년 + 사진 | 32ms |
| "2005년 아이들 영상 찾아줘" | 1ms |
| 내용 '계약금' | 3ms |
| 100번째 쪽 넘기기 | 1ms |

색인 크기: 100만 개에 약 0.7GB.

## 검증
- 엔진 자동 테스트 38개 통과(문서 추출, 색인·검색, 중단·재개, 하드 분리·재연결, 밤 시간, 권한 없는 폴더, API 전체 흐름, 백업·복원·초기화, 다른 기기 접속 보호, 문제 신고 파일에 내용 없음, 안전 규칙 자동 점검)
- 화면 자동 테스트(흐름 + 디자인) 통과 — 자세한 내용은 `docs/검증/1단계.md`
