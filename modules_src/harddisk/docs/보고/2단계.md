# 2단계 보고 — 사진·영상 날짜별 보기

## 만든 것
- 사진의 **촬영 날짜(EXIF)** 와 **장소(GPS)** 를 읽어 저장. 날짜가 없으면 파일 날짜 사용
- 장소는 인터넷 지도 없이 **내장 도시 목록으로 가장 가까운 도시 이름**(예: 속초)을 붙임 → 위치 정보가 밖으로 나가지 않음
- 영상: 촬영 날짜·길이(ffprobe 또는 mp4 머리 정보), 썸네일(ffmpeg)
- **썸네일 캐시**: 앱 폴더에 따로 저장, 설정에서 용량 한도(기본 2GB), 넘으면 오래 안 본 것부터 정리(원본 아님)
- 화면: 연도 타일 → 월 타일(대표 사진) → 큰 썸네일 격자, "사진만/영상만"
- **N년 전 오늘**: 같은 월·일의 옛 사진·영상을 해마다 묶어 보여주고 **음성으로 읽어줌**. 홈 맨 위 '오늘 할 일' 카드에도 표시
- **장소별 보기**: 오프라인 점 지도 + 장소 타일
- **TV 상영관 모드**: 큰 화면 자동 재생(사진 5초, 영상은 끝까지), 이전·다음·일시정지, 키보드(←→, 스페이스, Esc)
- 사진·영상 보기 화면에서 **음성 메모**(말로 남긴 기억이 그 파일에 붙고, 메모 내용으로도 검색됨)

## 검증
- API 테스트: 연도·월 묶음, 썸네일 생성, 원본 보기, 추억(3년 전 오늘 샘플), 장소(속초), 음성 메모 후 메모로 검색
- 화면 테스트: 연→월→사진, 추억, 장소, 상영관, 말로 메모 붙이기
