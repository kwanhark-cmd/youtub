# 3단계 보고 — 얼굴 인식 가족별 보기, 영상 장면 찾기, 가족 목소리 모음

## 만든 것
- **모델을 넣으면 켜지는 구조**: 얼굴(InsightFace), 장면(OpenCLIP). 모델이 없으면 화면에 "꺼져 있어요" + 설치 안내, 나머지는 그대로 동작
- **사람 화면**: 같은 사람 얼굴을 자동으로 묶어 얼굴 사진 격자로 보여줌 → 이름 붙이기 → **이름으로 검색**("민수 사진")
  - **두 사람 합치기**(같은 사람이 둘로 나뉜 경우), **"이 사람이 아니에요"**(잘못 묶인 사진 빼기) — 고친 결과는 다음 묶기에서도 유지
- **장면**: 사진 1장·영상 10초마다 장면을 보고 **꼬리표**(바다, 생일, 눈, 비 …)를 붙임. "비 오는 장면 찾아줘"처럼 말하면 **영상과 시작 시각**을 찾아 **그 부분부터 재생**
  - **장면 모음** 만들기·담기·빼기, 모음을 **상영관에서 이어서 재생**(각 장면 끝에서 다음으로)
  - **1번 앱용 내보내기 폴더**: 앱 폴더 `내보내기\(모음 이름)\` 에 장면 목록(JSON) + 잘라낸 영상 조각(원본은 그대로)
- **가족 목소리 모음**: 영상·녹음에서 **사람 목소리 구간**을 찾음(모델 없이 소리 크기·떨림으로). 구간에 이름을 붙이면 이름별로 모아 듣기. 파일 보기 화면에서 구간을 눌러 바로 듣기
- 모두 **백그라운드 처리**(색인의 추가 단계) → 일시정지·이어서·밤 시간 그대로 적용

## 이 환경에서의 한계
- 실제 모델 파일(수백 MB)은 받지 않았습니다. 대신 **시험용 가짜 모델**(색깔로 사람·장면을 흉내)로 묶기·합치기·이름·검색·모음·내보내기 흐름 전체를 시험했습니다. 실제 정확도는 모델을 넣은 PC에서 확인이 필요합니다(BLOCKERS 5).
