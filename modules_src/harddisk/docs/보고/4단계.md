# 4단계 보고 — 중복 파일 찾기

## 만든 것
- **크기로 먼저 거르고** → 같은 크기끼리 **앞부분(64KB) 비교** → 그래도 같으면 **전체 내용 비교(해시)**. 큰 하드에서도 읽는 양을 최소로
- 정리 화면: "똑같은 파일 N개 · 각각 크기", 정리하면 비울 수 있는 용량 표시, 묶음마다 **가장 오래된 원본에 '남기기 추천' 표시**
- **자동 삭제 없음.** 사용자가 고른 파일만 **'휴지통으로 이동'**(빨간 버튼) → **확인 창 2번** → 운영체제 휴지통(되살리기 가능)
- 진행 중에는 진행 숫자 표시, 다른 화면으로 가도 계속

## 검증
- `test_duplicates_and_trash_confirm`: 복사본 묶음 1개 찾음, 확인 없이 요청하면 거절·파일 그대로
- `test_trash_moves_to_os_trash`: 확인하면 운영체제 휴지통 함수로만 보냄, "되살릴 수 있어요" 안내
- 화면 테스트: 중복 찾기 → 휴지통 버튼 → 1단계 확인 → 2단계 "정말 할까요?" → 취소 → 파일 그대로
- 안전 자동 점검: 원본 삭제는 `trash.py` 한 곳뿐(영구 삭제 코드 없음)
