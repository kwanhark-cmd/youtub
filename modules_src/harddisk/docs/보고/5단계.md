# 5단계 보고 — 개인 기록 통합, 인맥 지도

## 만든 것
- **가져오기**
  - 구글 캘린더·주소록: 설정에 연결 정보(OAuth 클라이언트 ID·보안 비밀)를 넣고 "구글 연결하기" → 구글 로그인 → "지금 가져오기". **읽기 전용 권한**, 가져온 것은 이 PC에만 저장. 다시 가져오면 바뀐 것만 고침(중복 없음)
  - 파일로도 가능: 일정 **.ics**, 연락처 **.vcf**(옛 휴대폰의 깨진 한글 인코딩도 처리)
  - **구글 킵**: 테이크아웃 zip/json (휴지통 메모 제외, 체크리스트 ☑/☐, 라벨 → 프로젝트)
  - **워드 일기장 폴더**: 워드·한글·글 파일. 파일 이름이나 줄 맨 앞 날짜(2005-08-15, 2005년 8월 15일, 2005.8.15)로 날짜별 일기로 나눔
  - **음성 일기**: 마이크로 말한 내용이 글자로 적히고 날짜별 일기로 저장
- **통합 타임라인**: 일기·음성 일기·일정·킵 메모를 한 줄로, 월별 제목, 종류·연도·글자로 거르기. 기록 화면에서 **같은 날 찍은 사진·영상**도 함께
- **사람**: 이름·전화번호·이메일·관계·저장한 날·메모. 관계는 직접 적을 수 있음. 얼굴 이름과 같으면 **그 사람이 나온 사진**도 보여줌. **사람 정보 읽어주기**
- **이름 자동 연결**: 기록에 연락처 이름이 나오면 '확인 필요'로 연결 → "맞아요/아니에요"로 확인·수정, 직접 사람 추가. 거절한 연결은 다시 생기지 않음
- **인맥 지도**: 프로젝트·작품(킵 라벨, 일정 제목의 [대괄호]·《겹낫표》, 직접 추가)과 함께한 사람을 선으로 이은 그림(점선=확인 필요). 선을 누르거나 목록에서 **확인·수정**
- **통합 검색**: 한 검색창에서 파일·문서 내용·기록·연락처가 함께 나옴(이 앱의 차별점)
- **외부 AI 문서 요약**(기본 꺼짐): 설정에서 켜고 키를 넣었을 때만, 누르기 전에 "무엇이 전송되는지" 확인 창. 월 한도(원) 넘으면 멈춤, 사용 금액 기록

## 검증
- `tests/test_records.py` 7개: 가져오기 4종·중복 없음·최신순·옛 vcf 인코딩·이름 연결·통합 검색, 확인/거절/재연결, 인맥 지도, 음성 일기, 일기 날짜 나누기, **AI 꺼짐이면 인터넷 호출 0회**, AI 가짜 서버로 요약·한도 초과 거절, 구글 가짜 서버로 일정·연락처 가져오기·참석자 이름 연결
- 화면 테스트: 파일 3종 가져오기, 말로 일기 쓰기 → 저장 → 이름 연결 "맞아요", 인맥 지도 확인, 통합 검색
