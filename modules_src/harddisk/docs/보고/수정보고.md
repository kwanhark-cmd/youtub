# 수정 보고 — 1.1.0 (업데이트 방식·오류 대비·화면 재설계·앱 전용 수정)

## 바뀐 것
### 1. 업데이트 방식 — 색인·설정은 절대 그대로
- 색인·썸네일·설정·얼굴 이름·메모·인맥은 **자료 폴더**(`%LOCALAPPDATA%\HDBiseo`)에 있고, 설치 프로그램은 **프로그램 파일만** 바꿔요(AppId·설치 경로·이름 그대로).
- 설정 > 자료 관리에 **자료 위치 표시**, 다른 드라이브로 **옮기기**(복사→확인→전환, 원래 자료는 남김). 혹시 프로그램 폴더에 옛 자료가 있으면 1회 자동 이전.
- 색인 형식이 바뀌면 **자동 변환**(다시 분석 안 함), 변환 전 **자동 백업**. 이미 설정이 있으면 첫 실행 마법사를 건너뜀.
- 설정 맨 위 **"업데이트 확인"**: 새 버전 알림 → "지금 설치"(윈도우: 내려받아 설치 파일 실행) / 맥·안드로이드: 새 앱 내려받기. 설치 전 **설정·인물 정보 자동 백업**(색인 제외), **분석 중이면 "분석이 끝난 뒤 해 주세요"**, 보기 앱과 엔진 버전이 다르면 안내.
- GitHub Actions가 버전 태그(v1.1.0)에 맞춰 **Releases에 설치 파일 3종 + 한국어 변경 내역**(CHANGELOG.md)을 올려요.

### 2. 오류 대비
- **스크롤 위치 유지**: 자동 갱신은 바뀐 부분만 고치고, 목록을 보는 중 새 자료가 생기면 "새 자료가 있어요 · 새로 보기" 버튼만(누르면 보던 위치 그대로), 파일을 열었다가 **뒤로** 오면 보던 위치.
- **실패 → 다시 시도** 안전: 화면마다 새 상자에 그려서, 늦게 끝난 이전 작업이 새 화면을 건드리지 않음. 모든 오류 상자·알림에 **다시 시도·문제 신고**.
- 사용자에게 실패를 보여주는 모든 경우를 **단계(하드 접근/파일 읽기/추출/색인 저장/엔진 연결/구글/업데이트)와 함께 기록**. 열쇠·전화번호·이메일은 자동으로 가림.
- **상태 4가지 따로**(색인 / 얼굴 모델 / 구글 / PC 엔진) — 홈·설정에 표시, 저장 즉시 반영. 실제 폴더를 고르면 **체험용 예제 폴더 자동 숨김**.
- **파일 불러오기 버튼**: 구글 JSON, 얼굴 모델, 킵 테이크아웃, 일정·연락처 파일.
- 빈 폴더·하드 분리·엔진 꺼짐·모델 없음 → 오류 대신 안내 + 다음 행동 버튼.
- **앱 꾸미기**: 표시 이름(홈·창 제목에 바로), 아이콘(7가지 또는 내 사진), 색 테마 5가지, 바로가기용 .ico 받기 + 바꾸는 방법 그림.
- 함께 고친 문제: 첫 실행 때 상태 확인이 시작되지 않던 문제, 화면을 떠나도 영상 내려받기가 계속되던 문제, 홈 제목 고정, 시험에서 인터넷 함수 바꿔치기가 안 되던 문제.

### 3. 화면 재설계
- 홈: **화면 폭 전체의 큰 검색창(68px) + 치는 즉시 결과** → **오늘의 추억 사진 크게** → **사람 동그란 얼굴 줄** → **종류별 색 타일 2열**(사진 파랑·영상 보라·문서 주황·일기 초록·사람 분홍·정리 청록, 개수 표시) → **색인 진행 작은 띠**(큰 숫자 + 막대 + 상태).
- 테두리만 있는 상자 대신 **채운 카드 + 부드러운 그림자**, 어두운 모드 카드는 바탕보다 한 단계 밝게. 글자 4단계, 카드 간격 1.5배.
- 문서 목록: 종류 색 아이콘 + 이름 + 찾은 문장(노랑 형광펜). 사진·영상: 큰 썸네일 격자.
- **가상 스크롤**: 수만 개 목록·격자도 보이는 것만 그림(420장 달에서 그린 칸 200개 미만 확인).
- 설정: **그룹별 카드**(분석 폴더 / 실행 시간 / 얼굴 모델 / 구글 연결 / 보기 / 자료 관리 / 도움), **위험 동작은 맨 아래 빨강 카드**.

### 4. 이 앱 전용
- **얼굴 모델 라이선스 해결**: 기본 모델을 상업 사용 가능한 **OpenCV YuNet(MIT) + SFace(Apache-2.0)**로. 설정에 "개인 사용·판매 모두 가능 / 개인 사용용" 표시, InsightFace는 개인용 선택지로 남김. 대안 조사는 `docs/모델설치.md`.
- **"얼굴 인식 켜기" 버튼 한 번**: 내려받기(39MB) → 확인(sha256) → 제자리 → 바로 켜짐. 막히면 수동 "모델 파일 불러오기".
- **구글 연결 준비 도우미**: 콘솔 바로가기, Calendar·People API, 데스크톱 앱 유형, 테스트 사용자, "고급 → 이동", 7일 만료 안내 + JSON 불러오기.
- 다른 기기: **연결 번호 아주 크게**, 연결이 안 될 때 확인할 것 5가지.
- 윈도우: **PC 시작 시 자동 실행(기본 켜짐)** + 작업 표시줄 **트레이 아이콘(색인 진행률, 열기·멈춤·끝내기)**, 두 번 실행 방지.
- 마이크 장치가 없으면 마이크 버튼 대신 글자 입력칸.

## 업데이트 방법
1. 설정 맨 위 **업데이트 확인 → 지금 설치**. 또는
2. GitHub **Releases**에서 `HDBiseo-Setup-1.1.0.exe`를 받아 실행(덮어쓰기). 색인·설정은 그대로예요.

## 검증
- 엔진 시험 **70개 통과**(1.0.0 색인 업그레이드, 업데이트 차단·백업, 자료 옮기기, 모델 설치, 구글 JSON, 로그 가림, 실제 얼굴 모델 시험 포함), 린트 통과
- 화면 시험 **40개 통과**(스크롤 유지 2, 실패→다시 시도 2, 상태 표시, 앱 꾸미기, "가장 먼저 눈에 띄는 것", 가상 스크롤, 설정 순서, 마이크 없는 기기, 디자인 4종 등)
- 100만 개 검색: 가장 느린 것 **184ms**(0.2초 이내, 여유는 적음 — 연도+낱말+종류 조합)
- 원본 불변·외부 전송 없음 자동 점검 유지(인터넷 코드는 AI·구글·업데이트·모델 내려받기 4곳뿐, 모두 사용자가 누를 때만)
