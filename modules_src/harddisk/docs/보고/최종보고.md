# 최종 보고 — 컴퓨터 하드 자료 검색 정리 비서

## 한 줄 요약
1~5단계 기능을 모두 만들고, 이 환경에서 자동 테스트(엔진 54개 + 화면 흐름·디자인 검사)로 확인했습니다.
GitHub Actions에서 윈도우·맥·리눅스 엔진 테스트, 맥 앱, 안드로이드 앱 빌드가 통과했습니다.

## 완성한 기능
| 단계 | 내용 |
|---|---|
| 1 | 하드디스크 읽기 전용 색인(이어서·새 파일만·밤 시간·연결 끊김 대응·읽을 수 없음 목록), 이름·날짜·종류·크기·위치 검색(치는 대로), 한글·엑셀·워드·PDF 안의 글자 검색과 문장 미리보기, 말로 찾기 |
| 2 | 사진·영상 연·월별 보기, 촬영 장소, N년 전 오늘(읽어주기), 장소별 보기, TV 상영관, 음성 메모 |
| 3 | 얼굴로 사람 묶기·이름·두 사람 합치기·이 사람 아님, 장면 꼬리표·"비 오는 장면" 검색·그 시각부터 재생, 장면 모음·1번 앱용 내보내기 폴더, 가족 목소리 모음 |
| 4 | 중복 파일 찾기, 휴지통 이동(확인 2번, 자동 삭제 없음) |
| 5 | 구글 캘린더·주소록(읽기 전용), .ics/.vcf, 구글 킵, 워드 일기장, 음성 일기 → 통합 타임라인, 이름 자동 연결(확인·수정), 인맥 지도, 외부 AI 문서 요약(기본 꺼짐) |
| 공통 | 첫 실행 마법사, 큰 3D 타일 홈, 오늘 할 일, 밝은·어두운·고대비, 글씨 3단계, 움직임 줄이기, 가족별 사용자, 맥·안드로이드 접속(연결 번호), 백업·복원·초기화, 문제 신고 |

## 못 한 것과 이유
| 항목 | 이유 / 대안 |
|---|---|
| Flutter 보기 화면 | 이 환경에서 실행·검증 불가 → 지시서 대체안(웹 화면 + Electron + Capacitor)으로. 같은 화면이 윈도우·맥·안드로이드에서 동작 |
| 실제 얼굴·장면 모델로 정확도 확인 | 모델 파일을 쓰지 않음. 구조와 흐름은 시험용 가짜 모델로 확인. 모델 설치법: `docs/모델설치.md` |
| 실제 구글 계정 연결 | 가짜 구글 응답으로만 시험 |
| 윈도우 실제 PC 설치 확인 | Actions의 윈도우 서버에서 설치 파일 생성과 엔진 실행까지 자동 확인 통과(첫 시도 실패 → 수정). 실제 가정용 PC 설치는 사용자 확인 필요 |
| 일괄 편집, 외부 음성 서비스, 앱 안 '되돌리기' 버튼, Lottie | 누락점검 문서 참고 |

## 사용자가 처음 할 일
1. GitHub 저장소 → **Actions** → 최신 "검사와 빌드" → **HDBiseo-Windows-Setup** 내려받아 윈도우 PC에 설치
2. 바탕화면 아이콘 실행 → 마법사에서 글씨 크기, **분석할 하드디스크**(제외 폴더), 밤 시간 선택 → **색인 시작**
   (처음엔 "체험용 예제 폴더로 해보기"로 먼저 둘러봐도 좋아요)
3. 휴대폰·맥에서 보려면: 설정 → 다른 기기에서 보기 켜기 → 프로그램 다시 켜기 → 휴대폰 인터넷 창에 주소 입력 → 연결 번호 6자리
4. (선택) 얼굴·장면 인식: `docs/모델설치.md`
5. (선택) 구글 연결: 구글 클라우드 콘솔에서 'OAuth 클라이언트 ID(데스크톱 앱)' 만들기 → 캘린더·People API 사용 설정 → 설정 화면에 ID·보안 비밀 입력 → 기록 > 가져오기 > 구글 연결하기

## 권장 PC 사양
- 윈도우 10/11 64비트, 메모리 **16GB 이상**(최소 8GB), SSD에 색인 공간(파일 100만 개당 약 1GB + 썸네일)
- 얼굴·장면 인식을 쓸 때는 엔비디아 그래픽카드 권장(없으면 CPU로 느리게)

## 판매 단계에서 할 일
1. **모델 라이선스**: InsightFace buffalo_l 은 비상업용 → 상업 라이선스 얼굴 모델로 교체 또는 라이선스 구매. CLIP 가중치 라이선스 확인
2. **코드 서명**: 윈도우 설치 파일(인증서), 맥 앱(애플 개발자 공증), 안드로이드(서명 키·플레이 스토어)
3. **구글 OAuth 앱 검증**: 여러 사용자에게 팔려면 구글 앱 심사(민감 권한: 캘린더·주소록)
4. 설치 파일에 모델 자동 내려받기 화면, 자동 업데이트
5. 개인정보 처리방침·이용약관, 고객 문의 창구(문제 신고 파일 받는 곳)
6. 아이폰 앱(구조는 열어 둠), 집 밖 접속(첫 버전 제외)
7. 실제 대용량 하드(수 TB)에서 장시간 시험, 다양한 한글(HWP) 실제 파일로 추출 시험
