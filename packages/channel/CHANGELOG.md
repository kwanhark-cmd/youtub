# 변경 내역

## 1.2.0
- 고친 것: 메뉴를 오가거나 자료가 새로 고쳐질 때 스크롤이 맨 위로 튀던 문제, 실패 창의 "다시 시도"를 누르면 오류가 나던 문제
- 실패는 어느 단계(로그인·연결 정보·채널 목록·영상 목록)에서 났는지 로그에 남김. 오류 창 안에서 바로 "문제 신고 파일 만들기"
- 채널이 없는 구글 계정이면 안내 + "다른 계정으로 연결", 영상이 없는 채널도 등록
- 연습 모드 띠 대신 구글·인공지능 연결 상태를 따로 표시. 실제 채널이 생기면 연습 채널은 숨김 (설정 → 연습 자료 보기)
- 업데이트: 설정 맨 위 "업데이트 확인" (누를 때만 받고, 설치 전에 자동 백업). 새 버전 설치 = 덮어쓰기, 설정은 그대로
- 화면 새 단장: 크기로 중요도 (오늘 할 일이 가장 크게), 영역별 색 타일, 테두리 대신 채운 카드, 설정 묶음 카드 5개, 큰 썸네일 채널 카드
- 구글 연결 준비 마법사 (7단계, JSON 파일 불러오기, 7일 만료·확인되지 않은 앱 안내 그림)
- 앱 꾸미기: 앱 이름, 아이콘(5가지 색·내 그림, 안드로이드 홈 화면 아이콘), 색 묶음 4가지
- 윈도우는 설치 프로그램으로 설치 (시작 메뉴·바탕화면 바로가기)

## 1.1.0
- 화면 새 단장: 큰 3D 타일 홈, "오늘 할 일" 카드, 비서 마스코트, 원형 게이지, 상태 색(초록·파랑·노랑·빨강) 통일
- 밝게·어둡게·또렷하게(고대비) 보기, 움직임 줄이기, 누를 때 진동·소리
- 처음 쓰는 화면 안내 말풍선, 빈 화면 시작 버튼, 위험한 동작 2번 확인, 쉬운 말로 문구 정리
- 채널별 설명 템플릿 (고정 문구·링크·해시태그 자동으로 붙이기)
- 일괄 수정 미리보기 (고른 것만 적용, 방금 것 모두 되돌리기)
- 주목할 영상 (평소보다 조회수가 빨리 느는 영상을 홈에)
- 검색어 추천 (비용 표시)
- 게시 달력
- 썸네일 2개 만들어 고르기
