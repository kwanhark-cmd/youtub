# 바뀐 내용

## 1.1.0
- 새 버전 설치(업데이트)를 해도 물건·사진·사연·판매 상태·설정·AI 열쇠가 그대로 남아요.
- 설정 맨 위 "업데이트 확인" 버튼: 새 버전을 알려 주고, 누르면 자동 백업 후 내려받아 설치해요. 하루 한 번 조용히 확인해 홈에 "새 버전 있어요"를 띄워요.
- AI 열쇠를 기기의 보안 저장소에 보관해요.
- 오류가 나도 앱이 멈추지 않게 고쳤고, 모든 오류 창에 "다시 시도"·"문제 신고" 버튼이 있어요.
- 화면을 새로 꾸몄어요: 오늘 할 일이 맨 위에 크게, 사진 중심 물건 카드, 채워진 카드와 그림자.
- 앱 이름·아이콘·색 테마를 바꿀 수 있어요.
- 타임랩스를 유튜브용 MP4 영상(세로·가로)으로도 저장해요.
- 지메일에서 제미나이 정리 메일을 가져올 수 있어요 (구글 연결 도우미).
- 판매·폐기가 끝난 물건 사진을 정리해 용량을 줄일 수 있어요.
- 판매글 복사 뒤 "당근마켓 열기 / 번개장터 열기" 버튼.
